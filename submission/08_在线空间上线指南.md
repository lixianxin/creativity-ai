# 在线空间上线指南（提交项：空间地址链接）

> 目标：得到一个评委可直接打开、能在线预览运行的 URL；空间内具备 ≥10 个有效智能体（本项目 12 个）。
> 两个方案按提交页实际要求二选一，**需先确认提交页“空间”指哪一种**。

## 方案 A：提交页允许填外部应用 URL（推荐，委员会完整体验）

部署现有 Streamlit 应用到公网，约 15 分钟，全部点击操作。

### A1. Streamlit Community Cloud（免费）
1. 把项目推到 GitHub（仓库可设为 public；**推送前确认 [.gitignore](../../.gitignore) 已排除 `.streamlit/secrets.toml` 与 `data/*.db`**）。
   - 注意：`core/config.py` 历史版本含明文密钥，公开仓库后应在各平台控制台**轮换（重置）密钥**，再按下条注入新密钥。
2. 打开 https://share.streamlit.io 用 GitHub 登录 → New app：
   - Repository：本仓库；Main file path：`frontend/app.py`；Branch：main。
3. 在 App 的 Settings → Secrets 粘贴 [.streamlit/secrets.example.toml](../../.streamlit/secrets.example.toml) 内容并填入真实可用密钥（至少百炼一个），Deploy。
4. 得到 `https://<你的应用>.streamlit.app` URL，填入提交页"空间地址"。
5. 冒烟验收（按此顺序点）：首页可见 12 Agent 架构 → 粘贴演示项目 → 开始审查 → L0 八棒并行 → 最终出现终审结果与 12 份报告标签页。

### A2. 自有云服务器（备选）
```powershell
pip install -r requirements.txt
# Linux: export BAILIAN_API_KEY=sk-xxx ; Windows: $env:BAILIAN_API_KEY="sk-xxx"
python -m streamlit run frontend/app.py --server.port 8501 --server.address 0.0.0.0
```
前置 Nginx/安全组放行端口与 HTTPS（赛事页面一般要求可直接访问的链接）。

## 方案 B：提交页要求平台内"智能体空间"（如扣子/腾讯元器/Trae 空间类）

在平台内逐个新建 12 个智能体：
1. 打开 [space_agents/00_发布清单.md](space_agents/00_发布清单.md)，按 01–12 顺序逐个新建；
2. 每个文件里已备好：空间名称（创想∞·XX官）、一句话简介、开场白、系统提示词全文，直接复制粘贴；
3. 12 个均发布为"可独立使用"（满足 ≥10 有效智能体门禁）；
4. 若平台支持"工作流/多 Agent 编排"，再按 DAG 搭建：8 专家并行 → 红队 → 总指挥 → 评审 → 路演；
   不支持编排则在空间简介中写明"完整委员会流程见应用链接"，并同时走方案 A 作为串联体验入口。

## 演示项目文案（粘贴用，与所有真实 Run 一致）

```
创想∞ AI创业委员会：面向高校创新创业场景的 AI 评审系统。学生提交创业想法后，12个AI委员模拟真实创业委员会进行全链路审查。
目标用户：高校创新创业学生（免费），学校创业学院/教务处（机构版采购）
商业模式：学生免费，学校机构版按年采购。基于大模型API直接上线对外服务。
已有验证：目前2所学校创业学院老师口头表示感兴趣。
```

## 上线后必查

- [ ] 手机和电脑各打开一次 URL，首屏 ≤10 秒可交互
- [ ] 密钥不出现在任何公开文件（页面源码、GitHub、截图）
- [ ] 完整跑一次（或点"加载已有报告"展示真实 Run），终审结论正常
- [ ] 空间列表能看到 12 个智能体（方案 B）
- [ ] 提交页链接不指向 localhost / 127.0.0.1
