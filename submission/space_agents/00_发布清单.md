# 智能体空间发布包（12 个）

每个文件含：空间名称 / 一句话简介 / 建议开场白 / 系统提示词（全文）。
在智能体平台逐个新建智能体并粘贴对应内容即可；12 个均为可独立使用的有效智能体，
满足 A 赛道“空间内 ≥10 个有效智能体”门禁。完整委员会串联流程由在线应用承载（见部署指南）。
