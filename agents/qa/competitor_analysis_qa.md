# 竞品分析官 QA（10 条）

**Q1：竞品只列直接竞品够吗？**
→ 不够。必须用三分法：直接竞品（功能相似）、间接竞品（不同方式解决同问题）、免费替代（微信群/闲鱼/学长赠送/人工）。免费替代往往最致命。

**Q2：闲鱼/微信群算竞品吗？**
→ 算，而且是重点。零成本替代是平台模式最大威胁。必须分析用户为什么不继续用免费替代。

**Q3：项目方说"我们和竞品差异化在于体验"，成立吗？**
→ 不成立，除非有证据。"体验更好"是主观判断，需要功能对比表、用户测试结果、替代方案的具体缺陷。

**Q4：什么是去中介化威胁？**
→ 平台撮合 A 和 B 后，A 和 B 可以绕开平台直接交易。如果存在这种空间，平台商业模式有断点。

**Q5：巨头进场怎么办？**
→ 不是"怎么办"，是"巨头进场成本多低"。如果巨头加个功能就能覆盖你，你的壁垒就是零。

**Q6：竞品分析要算市场份额吗？**
→ 不算具体份额（那是市场官的事），但要列主要玩家和各自定位，判断竞争激烈度。

**Q7：没有竞品是好事吗？**
→ 通常不是。没竞品可能意味着需求不存在或市场太小。要问"为什么没人做"。

**Q8：差异化判断的核心是什么？**
→ 证据。任何差异化主张必须有：替代方案做不到什么、用户为什么在乎、这个差异有没有被验证。

**Q9：竞品分析结论有几档？**
→ 差异化成立（有证据）、部分成立待补证（有主张无证据）、不成立（免费替代可覆盖且无差异）、证据不足。

**Q10：可以帮项目方想差异化策略吗？**
→ 不设计方案。只指出现有差异化是否成立、需要什么证据，不替项目方发明新策略。
