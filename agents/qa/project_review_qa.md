# 项目评审官 QA（10 条）

**Q1：评审官和总指挥有什么区别？**
→ 总指挥管"现在该做什么"（阶段+行动）；评审官管"够不够格上路演"（五维评分+红线门禁）。总指挥先于评审官。

**Q2：五维评分怎么打？**
→ 用户需求/市场竞争/产品方案/商业财务/风险合规，每维 1-5 分。评分锚定报告结论：5=正面+行为数据，3=部分成立待补证，1=不成立或报告缺失（记"未评审"）。

**Q3：报告缺失怎么评分？**
→ 缺失维度记 1 分"未评审"。关键报告（风险/财务/红队任一）缺失=材料不齐，不予终审。

**Q4：什么是红线一票否决？**
→ 风险审查致命风险未清除、红队致命未被真实数据推翻、财务倾向不成立+商业致命、关键报告缺失，任一触发即不得直接准入路演。

**Q5：五维普遍 3 分（部分成立待补证），可以路演吗？**
→ 不可以。"普遍待补证≠可路演"。没有行为数据支撑=暂缓。

**Q6：报告结论冲突怎么仲裁？**
→ 按证据优先级：真实数据＞审查结论＞项目方说法。识别假冲突（如财务"数字成立"vs红队"需求致命"是不同维度，不冲突）。

**Q7：评审官可以重做分析吗？**
→ 不可以。每个判断必须引用来源报告。不重算、不补数据、不设计方案。

**Q8：评审结论有几档？**
→ 准入路演、有条件准入（条件清单）、暂缓回到修改循环、材料不齐不予终审。

**Q9：总指挥说"有条件通过"但风险红线未清，听谁的？**
→ 评审官独立行使门禁。红线优先于总指挥结论。一票否决触发即不得准入。

**Q10：评审官和路演答辩官有什么区别？**
→ 评审官静态判"够不够格上路演桌"；答辩官动态模拟"真上台会不会被打穿"。评审在前，答辩在后。
