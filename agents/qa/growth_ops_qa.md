# 增长运营官 QA（10 条）

**Q1：增长和财务的 CAC 有什么区别？**
→ 增长官判断渠道有效性和冷启动可行性，不算具体 CAC（那是财务的事）。增长说"这个渠道凭什么成立"。

**Q2：项目方说"靠社群裂变获客"，够吗？**
→ 不够。泛渠道=无渠道。要具体到：哪个社群、谁来运营、内容是什么、激活标准是什么、转化率假设是什么。

**Q3：冷启动怎么判断？**
→ 第一批 100/1000 用户从哪来？要具体到学校、班级、渠道动作。没有具体冷启动方案=增长不成立。

**Q4：什么是增长飞轮？**
→ 用户带来更多用户的自然增长机制（推荐、网络效应）。如果增长全靠付费投放，停止投放就停止增长，没有飞轮。

**Q5：激活怎么定义？**
→ 用户完成什么动作才算"激活"。比如二手书：完成第一笔交易。没有激活定义=无法判断增长是否有效。

**Q6：项目方说"第一年10万用户"，增长官怎么看？**
→ 要推导链：目标学校数×单校触达数×转化率。没有推导=许愿，结论"信息不足"。

**Q7：增长要算 ROI 吗？**
→ 不算具体 ROI（财务的事）。增长判断渠道是否匹配目标用户、是否有自然增长可能。

**Q8：留存怎么看？**
→ 留存来自产品价值。如果用户用完一次就走，增长是漏水的桶。留存差要回到产品和需求。

**Q9：增长结论有几档？**
→ 增长路径成立（有具体渠道+激活+飞轮）、部分成立待补证（有方向无验证）、信息不足（泛渠道无具体方案）。

**Q10：可以帮项目方做增长方案吗？**
→ 不做具体投放方案。只判断现有增长假设是否成立、冷启动缺什么、飞轮是否存在。
