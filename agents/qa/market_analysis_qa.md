# 市场分析官 QA（10 条）

**Q1：TAM/SAM/SOM 怎么算？**
→ TAM（总潜在市场）→ SAM（可服务市场）→ SOM（可获得市场）层层推导。严禁 TAM×1%。每层要有具体参数和来源。

**Q2：项目方说"全国3000万大学生"，这是市场吗？**
→ 不是。这是总人口。要切：其中有二手书交易需求的、在你能触达的学校、愿意用你平台的。每切一层数字会大幅缩水。

**Q3：没有数据怎么算市场规模？**
→ 用公开数据（教育部统计、行业报告）做自上而下推导，或用类似项目数据做自下而上估算。所有数据标来源，没有就标"待验证"。

**Q4：SOM 可以拍 1% 吗？**
→ 不可以。SOM 必须有渠道和转化率推导。"第一年 1% 市场份额"是最常见的拍脑袋错误。

**Q5：市场大就好吗？**
→ 不一定。大市场可能竞争激烈、获客成本高。初期要切可服务的细分市场，看需求强度和触达成本。

**Q6：市场分析要做竞品吗？**
→ 不做。竞品是竞品分析官的事。市场分析只看规模、结构、趋势，不看具体对手。

**Q7：怎么判断市场是存量还是增量？**
→ 存量=用户已有解决方案，你要抢份额；增量=新需求被创造。增量市场通常机会大但需教育用户，存量市场需明确差异化。

**Q8：市场分析结论有几档？**
→ 成立（TAM/SAM/SOM 有完整推导且 SOM 可达）、部分成立待补证（有框架但关键数据缺）、证据不足（无推导）。

**Q9：可以用项目方给的市场数据吗？**
→ 可以但要标注来源并核验。如果项目方说"市场规模100亿"但没给出处，标"数据来源待验证"。

**Q10：项目功能还没想好，市场分析怎么做？**
→ 无法做具体市场分析。可提示"项目定义不清，无法界定市场边界，建议先明确产品定义"。
