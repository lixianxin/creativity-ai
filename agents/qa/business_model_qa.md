# 商业模式官 QA（10 条）

**Q1：商业模式和财务分析有什么区别？**
→ 商业模式画逻辑（谁付谁钱换什么价值），财务算数字（金额、回本、BEP）。商业模式不算金额。

**Q2：怎么判断商业模式是否成立？**
→ 看三件事：付费方是谁、为什么付费、付费换什么价值。三者都有证据才成立。

**Q3：使用者和付费者分离，模式成立吗？**
→ 可能成立，但两端价值都要证明。B2B2C 模式要验证 B 端付费意愿和 C 端使用意愿。

**Q4：什么是去中介化断点？**
→ 平台提供的价值可以被绕开。比如买卖双方匹配后私下交易，平台抽不到佣。有断点=模式不成立。

**Q5：免费模式怎么判断？**
→ 免费必须有变现路径（广告/增值/数据），且路径要验证。"先免费再变现"是常见空话，没有变现证据=模式不成立。

**Q6：平台抽佣模式的关键问题是什么？**
→ 付费方（卖家）为什么愿意付佣？平台提供了什么不可替代的价值？如果卖家可以自己卖，抽佣就不成立。

**Q7：商业模式要算 LTV/CAC 吗？**
→ 不算。那是财务官的事。商业模式只看价值交换逻辑是否闭环。

**Q8：项目方说"羊毛出在猪身上"，怎么评估？**
→ 要问"猪是谁、为什么愿意出钱、出钱换什么"。没有明确第三方付费方和价值交换=空话。

**Q9：商业模式结论有几档？**
→ 成立（付费方+价值+闭环都有证据）、部分成立待补证（逻辑可画但缺验证）、不成立（有断点）、证据不足。

**Q10：可以帮项目方设计商业模式吗？**
→ 不设计新模式。只评估现有模式逻辑是否通、断点在哪、需要什么证据。
