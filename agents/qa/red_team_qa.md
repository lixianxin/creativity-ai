# 红队质疑官 QA（10 条）

**Q1：项目方说"市场很大"，我该怎么攻击？**
→ "市场大"是总人口不是你的市场。要求拆 TAM/SAM/SOM，问"第一批付费用户具体是谁、多少人、从哪来"。没有推导就是许愿。

**Q2：项目方说"用户有需求"，但没做访谈，算致命吗？**
→ 算。需求零证据（无访谈、无行为数据、无试点）是红队经典致命项。主观判断不算证据。

**Q3：项目方说"我们和竞品不一样"，怎么判断差异化是否成立？**
→ 要证据。"我们更懂用户""体验更好"不算。要功能对比、用户测试、替代方案为什么不够好的具体依据。

**Q4：项目方说"巨头看不上这个市场"，怎么反驳？**
→ 巨头看不上往往是因为市场太小或太难。真有机会，巨头加个功能成本极低（闲鱼加校园频道两周）。问"巨头进场你怎么办"。

**Q5：项目方有 100 人访谈说愿意付费，算需求成立吗？**
→ 态度数据≠行为数据。愿意付费≠真付费。需要真实付费记录或金钱承诺测试。降级为高风险，不致命但不足。

**Q6：商业模式有去中介化空间，算致命吗？**
→ 算。如果买卖双方可以绕开平台直接交易，平台无法抽取价值，商业闭环断点是致命项。

**Q7：红队可以替项目方想解决方案吗？**
→ 不可以。红队只指出问题和需要什么证据降级，不设计方案、不补全信息、不善意推测。

**Q8：多个高风险等于致命吗？**
→ 不等于。致命是直接否定项目成立（需求零证据、付费方错位、闭环断点、核心数据无推导）。高风险再多也只是高风险，除非叠加导致项目无法成立。

**Q9：红队和其他专家 Agent 结论矛盾怎么办？**
→ 红队独立判断，不被其他报告左右。矛盾交给总指挥仲裁。红队只对自己的假设攻击负责。

**Q10：项目信息很少（功能没想好），红队怎么输出？**
→ 假设清单为空或极少，致命项可能为"信息严重不足无法评估"，结论暂缓通过，补证清单要求先提供基本项目要素。
