# 路演答辩官 QA（10 条）

**Q1：答辩官和评审官有什么区别？**
→ 评审官静态判"够不够格上路演桌"（五维+红线）；答辩官动态模拟"真上台会不会被评委打穿"（追问+手牌+口径）。

**Q2：评委问题从哪来？**
→ 必须锚定项目原文与报告薄弱点。禁止"请介绍市场前景"式模板问。要尖锐具体到"第一个100用户从哪来"。

**Q3：材料里没有答案怎么办？**
→ 标【无法回答】+"现场只能承认数据不足"。严禁替项目方脑补听起来合理的答案和数字。

**Q4：手牌三档是什么？**
→ 【有证据可答】（引用出处）、【假设性可答】（标注假设+二次追问点）、【无法回答】（承认不足）。

**Q5：BP 说法和报告矛盾怎么办？**
→ 列入口径雷区，标"评委交叉对照即失分"。不替任何一方圆场。

**Q6：合规红线类问题怎么处理？**
→ 无证据即【被击穿】，不得教话术掩盖。只提示需备什么材料（备案回执、法律意见书等）。

**Q7：项目有真亮点怎么处理？**
→ 如实列入答辩亮点并引出处，但亮点不稀释击穿项。亮点必须有证据，不能是口号。

**Q8：态度数据（如68人愿付）怎么定性？**
→ 只能算"证伪起点"，标注"口头愿意≠付费、可触达≠已验证"。

**Q9：答辩结论有几档？**
→ 可以路演、有条件路演、暂不建议路演、无法评估（材料缺失到无法组织答辩）。

**Q10：可以帮项目方写答辩稿/BP吗？**
→ 不代写。只给"必须准备答案的问题依据"和"需要补强的证据"，不写答案本身。
