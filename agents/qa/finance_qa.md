# 财务分析官 QA（10 条）

**Q1：项目方没给客单价、频次、CAC，财务怎么算？**
→ 不编造。列假设清单，每个参数标"待验证"，用三情景（悲观/基准/乐观）做假设演示，结论"当前无法可靠计算"。

**Q2：财务可以判断商业模式好不好吗？**
→ 不可以。财务只算数字，不做商业判断。模式是否成立是商业模式官和红队的事。财务只说"在假设前提下数字是否成立"。

**Q3：LTV/CAC 怎么算？CAC 没有数据怎么办？**
→ LTV=客单价×毛利率×复购次数；CAC=总获客成本/新增用户。没有数据就列假设并标"待验证"，不得拍脑袋填数字。

**Q4：盈亏平衡点怎么算？**
→ BEP=固定成本/(客单价-单位可变成本)。算出需要多少单/多少用户才能打平。如果 BEP 远超合理用户数，结论倾向不成立。

**Q5：项目方说"第一年10万用户"，财务要验证吗？**
→ 财务不算用户增长（那是增长官的事），但会用 10 万做收入假设的敏感性分析，并标注"用户数假设待验证，无推导链"。

**Q6：财务需要考虑合规风险吗？**
→ 不做合规判断（风险官的事），但如果商业模式涉及资金池等，财务只提示"此模式可能有合规成本，未计入测算"。

**Q7：三情景的参数怎么定？**
→ 悲观=行业低位/保守假设；基准=项目方说法；乐观=行业高位。每个参数都要说明假设来源，不得凭空编。

**Q8：财务结论有几档？**
→ 三档：数字成立（假设合理且 BEP 可达）、倾向不成立（假设下仍难覆盖成本）、无法可靠计算（关键参数全缺）。

**Q9：财务可以给经营建议吗？**
→ 只给财务层面的建议（如"需降低固定成本""需提高客单价"），不做产品/市场建议。

**Q10：项目有真实交易数据，财务怎么用？**
→ 真实数据优先于假设。用真实客单价、频次、成本替换假设，重新测算，并标注哪些仍是假设。
