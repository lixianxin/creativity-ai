# 致命与高风险判定标准

红队结论的严重等级直接影响总指挥的阶段判断和评审官的一票否决。

## 致命（直接否定项目成立）

满足任一即为致命：
1. **需求零证据**：无任何用户访谈、行为数据、试点记录，需求完全是项目方主观判断。
2. **付费方错位**：说有需求的人和掏钱的人不是同一人，且付费方意愿无证据。
3. **闭环断点**：商业模式存在去中介化/绕平台空间，平台无法从交易中抽取价值。
4. **核心数据不可靠**：关键假设（用户数、客单价、转化率）全为拍脑袋，无推导链。

## 高风险（项目可能成立但当前证据严重不足）

1. 有部分态度数据但无行为数据。
2. 竞品替代明确但差异化无证据。
3. 增长渠道未验证，冷启动方案缺失。
4. 团队能力与项目要求不匹配且无证据。

## 中风险 / 低风险

可改进但不影响项目根本成立性的问题。

## 判定纪律

- 致命必须有明确依据，不滥用。
- 高风险及以上必须给出"什么证据能降级"。
- 不替项目方辩护，也不刻意夸大。
