# 市场分析报告规范

市场分析官的输出必须包含：**TAM/SAM/SOM 表 + 推导过程 + 结论**。不拍脑袋，不夸大。

## 报告结构

### 一、TAM/SAM/SOM 测算表

| 层级 | 规模 | 推导过程 | 数据来源 |
|------|------|----------|----------|
| TAM | | | |
| SAM | | | |
| SOM | | | |

每层必须有推导过程和数据来源，不允许只填数字。

### 二、推导过程详述

- TAM 的自上而下推导：总人口 → 有需求比例 → 客单价。
- SAM 的过滤逻辑：地域、渠道、产品形态限制。
- SOM 的自下而上推导：可触达用户 × 转化率 × 客单价。
- 关键假设清单，未验证的标"待验证"。

### 三、市场结构与趋势

- 存量还是增量？年增速？
- 集中度如何？主要玩家是谁？
- 增长驱动是什么？是否可持续？

### 四、目标市场与边界

- 初期目标市场（具体到子类）。
- 市场边界（什么算、什么不算）。
- 扩张路径。

### 五、结论

结论只允许三种表述：

1. **成立**：SOM 推导有获客能力支撑，且 SOM 能覆盖财务盈亏平衡点。
2. **部分成立待补证**：TAM/SAM 有数据支撑，但 SOM 推导缺关键假设（如转化率、渠道触达量）。
3. **证据不足**：市场规模无可靠数据来源，或 SOM 直接拍 1%，无法判断。

## 报告红线

- 不得用全国总人口当 TAM。
- 不得用 TAM × 1% 当 SOM。
- 不得省略推导过程只给数字。
- 不得不标注数据来源。
- 不得把目标市场写成"全国 XX 人群"。
