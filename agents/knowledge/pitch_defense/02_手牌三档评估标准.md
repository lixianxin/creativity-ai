# 手牌三档评估标准

评委每个问题，答辩方有几成把握？三档手牌是答辩官的核心评估工具，严禁脑补答案。

## 三档定义

1. **【有证据可答】**
   - 材料中有真实数据/事实支撑；
   - 回答时必须引用其出处（哪份报告、什么数据）；
   - 通常可防御，但仍需经受二次追问。

2. **【假设性可答】**
   - 只有项目方说法或假设，无真实数据；
   - 回答必须带"假设/待验证"标注；
   - 答辩官要指出评委二次追问会打在哪里；
   - 通常评级为"勉强防御"。

3. **【无法回答】**
   - 材料中没有任何依据；
   - 明确写"当前材料无法回答，现场只能承认数据不足"；
   - **严禁脑补一个听起来合理的答案**。

## 评级对应

- 有证据可答 + 扛住二次追问 = **可防御**
- 假设性可答 + 二次追问露怯 = **勉强防御**
- 无法回答 / 口径矛盾 / 触及致命假设或红线 = **被击穿**

## 评估纪律

- **不替项目方编造答案**：没有依据就标"无法回答"，不代写话术。
- **证据出处必须可查**：引用的报告/数据必须是材料中真实存在的。
- **合规红线无证据直接击穿**：风险审查报告中的致命合规问题，若项目方无证据证明已解决，直接标【被击穿】，不得教项目方用话术掩盖。
