# 免费替代威胁

免费替代是学生创业最容易忽视、却最常致命的竞争力量。它不是一个产品，而是一套"够用就行"的低成本行为组合。

## 一、常见免费替代形态

- **微信群/QQ群**：群主人工维护交易信息，买卖双方直接沟通。
- **闲鱼/转转**：通用二手平台，搜索成本极低，已有大量用户。
- **学长学姐赠送**：毕业季批量甩卖或直接送，建立在熟人关系上。
- **学校BBS/贴吧**：存量用户多，发帖免费，版主提供基础信用背书。
- **线下告示栏/宿舍群**：物理空间内的信息分发，零线上成本。

## 二、免费替代为什么强

1. **迁移成本为零**：用户不需要下载、注册、学习。
2. **信任成本低**：熟人关系或平台已有的信用体系。
3. **供给已存在**：不需要你去冷启动供给侧。
4. **人工灵活性高**：群里一句话就能完成的协商，产品要做十个功能。

## 三、分析框架

对每个免费替代，回答四个问题：

1. 它解决了用户的哪个核心场景？
2. 它的成本是什么（时间、信任、风险）？
3. 你的产品在哪一点上能显著优于它？
4. 这个优势是否可被对方用低成本方式复制？

## 方法论要点

- 如果你的产品优势只是"更方便"，免费替代会用"已经够用"打败你。
- 只有当免费替代存在明确的、高频的痛点（如信任缺失、信息过载、履约无保障），且你的产品能用系统化方式解决，才有机会。
- 不能打败的免费替代，就想办法接入或利用它（如把微信群作为获客入口）。
