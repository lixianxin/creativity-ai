# 竞品分析框架

五维对比法是竞品分析的标准工具。每个维度都要找证据，不能凭感觉打分。

## 一、功能维度

- 核心功能是否齐全？
- 有无独有功能？
- 功能完成度（可用 / 半成品 / 缺失）？
- 关注：竞品做了什么、没做什么，没做的可能是机会也可能是坑。

## 二、价格维度

- 定价模式（免费 / 抽佣 / 会员 / 一次性）？
- 价格水平对比？
- 是否有补贴、优惠？
- 关注：价格背后的成本结构和盈利空间。

## 三、体验维度

- 核心任务完成路径有几步？
- 新用户上手成本？
- 界面美观度、流畅度？
- 有无明显体验短板？
- 关注：用户评论中的高频好评和差评。

## 四、渠道维度

- 获客渠道（应用商店、社交媒体、地推、KOL）？
- 运营动作频率？
- 品牌声量？
- 关注：竞品的流量从哪来，成本多少。

## 五、壁垒维度

- 技术壁垒？
- 资源壁垒（独家供给、牌照、资金）？
- 网络效应？
- 品牌壁垒？
- 关注：如果巨头进场，竞品能不能守住。

## 六、对比表格式

| 维度 | 我方 | 直接竞品A | 间接竞品B | 免费替代C |
|------|------|-----------|-----------|-----------|
| 功能 | | | | |
| 价格 | | | | |
| 体验 | | | | |
| 渠道 | | | | |
| 壁垒 | | | | |

## 方法论要点

- 至少包含一个直接竞品、一个间接竞品、一个免费替代。
- 每个维度的结论必须有具体证据支撑，不能只写"好/不好"。
- 对比的目的不是证明我更强，而是找到真正的机会窗口和风险点。
