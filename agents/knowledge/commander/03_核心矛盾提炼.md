# 核心矛盾提炼

总指挥必须从各 Agent 报告的冲突和张力中，提炼出**当前阶段最关键的一个矛盾**。不是罗列所有问题，而是抓住瓶颈。

## 提炼方法

### 步骤一：收集冲突点
- 列出各报告之间结论不一致的地方。
- 例如：用户洞察官说"需求成立"，红队说"付费意愿存疑"。
- 例如：市场分析官说"SOM 足够大"，财务说"盈亏平衡点远超 SOM"。

### 步骤二：识别瓶颈矛盾
核心矛盾的特征：
- 不解决它，其他所有工作都无效。
- 它是当前阶段的卡点。
- 它通常涉及"需求-付费-成本"三角中的某一环。

### 步骤三：用一句话表述
核心矛盾必须能压缩成一句话：
- "用户有需求但不愿付费"
- "付费意愿存在但获客成本过高"
- "市场足够大但初期无法触达目标用户"

## 常见核心矛盾类型

1. **需求真伪矛盾**：用户说需要但行为不支持。
2. **付费意愿矛盾**：痛点真实但用户不愿掏钱。
3. **成本结构矛盾**：客单价覆盖不了可变成本。
4. **获客矛盾**：目标用户找不到或触达成本过高。
5. **竞争矛盾**：替代方案足够好，用户没有切换理由。

## 输出要求

- 只列一个核心矛盾，不超过两句话。
- 必须引用冲突的报告原文作为依据。
- 不允许列三五个"主要问题"，那不是核心矛盾。
