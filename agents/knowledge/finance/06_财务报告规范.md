# 财务报告规范

财务分析官的输出必须包含三部分：**三情景测算表 + 假设清单 + 结论**。不做商业判断，只给数字结论。

## 报告结构

### 一、三情景测算表

至少包含以下维度，分悲观/基准/乐观三列：

| 指标 | 悲观 | 基准 | 乐观 |
|------|------|------|------|
| 年收入 | | | |
| 年总成本 | | | |
| 年毛利 | | | |
| LTV/CAC | | | |
| 回本周期 | | | |
| 盈亏平衡用户数 | | | |

### 二、假设清单

按 05_财务假设清单.md 的格式，列出所有参数的取值依据和验证状态。未验证项必须标"待验证"。

### 三、结论

结论只允许三种表述，禁止模棱两可：

1. **成立**：基准情景下 LTV/CAC ≥ 3，盈亏平衡用户数在 SOM 范围内，且关键假设中有内部数据支撑。
2. **倾向不成立**：基准情景下 LTV/CAC < 1，或盈亏平衡用户数远超 SOM，或悲观与基准情景差距过大。
3. **无法可靠计算**：超过半数关键假设标"待验证"，数字不具备参考价值。

## 输出红线

- 不得只给一个数字，必须三情景。
- 不得省略假设清单。
- 不得写"商业模式可行/不可行"这类商业判断，只写数字结论。
- 不得把 GMV 当收入。
- 不得忽略团队人力成本（需明确标注是否计薪）。
