# 关键指标定义与口径

财务分析必须统一指标口径，否则数字无法比较。以下是学生创业项目高频指标的标准定义。

## 客单价 (ARPU / AOV)

- **ARPU**（每用户平均收入）= 总收入 / 总用户数，分母含未付费用户。
- **AOV**（客单价）= 总收入 / 付费订单数，仅统计付费行为。
- 两者不可混用，报告中必须说明用的是哪个。

## 复购频次

- 指单个付费用户在单位时间内的购买次数。
- 订阅制产品频次=1（按周期计费），复购体现为续费率。
- 频次口径必须与收入公式中的频次一致。

## 转化率

- **付费转化率** = 付费用户数 / 活跃用户数。
- **注册转化率** = 注册用户数 / 访问用户数。
- 说"转化率"必须注明是哪一级转化，禁止含糊。

## 获客成本 (CAC)

- **CAC** = 获客总费用 / 新增付费用户数。
- ** blended CAC**：含自然流量的综合获客成本。
- **paid CAC**：仅付费渠道的获客成本。
- 必须区分 paid CAC 与 blended CAC，两者数值差异很大。

## 留存率

- **次日/7日/30日留存率** = 对应天数后仍活跃的用户数 / 新增用户数。
- 月留存率用于估算生命周期：生命周期 ≈ 1 / 月流失率。
- 留存率是 LTV 计算的关键参数，无数据时标"待验证"。

## 毛利率

- **毛利率** = (收入 - 可变成本) / 收入。
- 必须扣除履约成本、支付手续费等直接成本。
- 平台型项目的收入是佣金而非 GMV，毛利率计算基于佣金收入。
