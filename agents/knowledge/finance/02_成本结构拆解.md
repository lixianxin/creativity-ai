# 成本结构拆解

学生创业团队的成本项往往被低估。必须按固定/可变/边际三层拆解，不允许只列总成本。

## 固定成本

不随用户量变化的成本，项目启动即产生：
- **人力成本**：团队成员薪资或机会成本。学生团队常忽略，必须明确标注"是否计薪"。
- **技术基础设施**：服务器、域名、云服务、第三方 API 订阅费。
- **办公与运营**：场地、水电、工商财税、法务。
- **工具与软件**：设计、协作、数据分析工具订阅。

## 可变成本

随用户量或订单量线性变化的成本：
- **获客成本 (CAC)**：投放、渠道分成、地推物料。
- **履约成本**：物流、仓储、售后、客服人力。
- **内容/服务成本**：内容生产、师资、运营活动。
- **支付与平台手续费**：支付通道费率、应用商店抽成。

## 边际成本

每新增一个用户/订单的额外成本：
- 纯软件产品边际成本趋近于零，但服务器和带宽会随规模上升。
- 涉及线下履约的项目，边际成本不可忽略。
- 边际成本决定规模化后的利润率走势。

## 学生团队常见漏项

- 忽略自己的时间成本
- 忽略服务器扩容成本
- 忽略支付手续费和退款损耗
- 忽略合规成本（备案、资质、许可证）

每一项成本必须说明取值依据，无依据标"待验证"。
