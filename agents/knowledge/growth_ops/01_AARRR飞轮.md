# AARRR飞轮

AARRR 是增长运营的核心框架，五个环节构成一个飞轮。飞轮转起来，增长就会自我加速；转不起来，投再多钱也没用。

## 一、五个环节

### 1. 获客（Acquisition）
用户从哪里来？渠道是什么？
- 关注：渠道数量、质量、成本。
- 指标：新增用户数、渠道转化率。

### 2. 激活（Activation）
新用户是否体验到了核心价值？
- 关注：用户完成核心任务的比例。
- 指标：激活率、核心任务完成率。

### 3. 留存（Retention）
用户是否会回来？
- 关注：次日、7日、30日留存。
- 指标：留存率、活跃天数。

### 4. 变现（Revenue）
用户是否产生收入？
- 关注：付费转化率、客单价。
- 指标：付费率、ARPU、LTV。

### 5. 推荐（Referral）
用户是否愿意推荐给他人？
- 关注：自然推荐、K 因子。
- 指标：邀请率、邀请转化率、K 值。

## 二、飞轮逻辑

```
获客 → 激活 → 留存 → 变现 → 推荐
 ↑                                    |
 └────────────────────────────────────┘
```

- 推荐带来新的获客，飞轮开始自转。
- 变现的钱可以投入获客，加速飞轮。
- 留存是飞轮的核心——留不住，前面所有环节都白费。

## 三、飞轮转不起来的信号

- 获客成本高于用户终身价值（CAC > LTV）。
- 激活率低，大量用户注册后不用。
- 留存率持续下滑，用户来了就走。
- 推荐率为零，全靠付费获客。

## 方法论要点

- 五个环节要按顺序看，不能跳。前面的环节没做好，后面的投入都是浪费。
- 飞轮的核心是留存和推荐，不是获客。
- 不要只看总用户数，要看每个环节的转化率。
