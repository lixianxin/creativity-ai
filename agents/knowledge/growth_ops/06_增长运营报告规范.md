# 增长运营报告规范

增长运营报告的核心是：飞轮能不能转、冷启动怎么启动、渠道是否有效，最终给出明确结论。

## 一、报告结构

### 1. 飞轮图

画出 AARRR 五环节，标注每一环的：
- 当前状态（已有数据 / 待验证）
- 关键指标目标
- 主要风险点

### 2. 冷启动方案

- 第一批用户从哪来（具体到渠道和动作）
- 先撬供给侧还是需求侧
- 预计冷启动周期和目标用户数
- 执行人和时间表

### 3. 渠道有效性分析

对每个候选渠道评估：
- 匹配度（高/中/低）
- 可控性（高/中/低）
- 可扩展性（高/中/低）
- 初步测试结论

### 4. 激活定义

- 明确激活动作是什么
- 当前激活率（如有数据）
- 提升激活的计划

### 5. 结论

- 飞轮是否能转起来
- 冷启动方案是否可执行
- 主要风险和待验证事项

## 二、方法论要点

1. 飞轮图必须画出来，不能只写文字。
2. 冷启动方案必须有具体渠道和动作，不能写"通过社交媒体推广"。
3. 渠道评估必须具体，"线上线下结合"等于没说。
4. 激活定义必须与核心任务一致。
5. 不算 CAC，但要判断渠道成本是否可控。
6. 结论要明确指出飞轮是否存在、冷启动是否可行。
