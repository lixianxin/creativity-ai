# 增长飞轮识别

增长飞轮是指用户增长能自我驱动的机制。有飞轮的产品增长会越来越快，没有飞轮的产品每一步增长都要靠外力（花钱）推动。

## 一、两种增长模式

### 自然增长（飞轮驱动）
- 用户因为产品价值自发推荐、自发传播。
- 每新增一个用户，会带来更多新用户。
- 成本随规模递减，甚至趋近于零。

### 付费增长（外力驱动）
- 每一个新用户都需要花钱获取（广告、补贴、地推）。
- 停止投入，增长就停止。
- 成本随规模线性增长。

## 二、飞轮的常见类型

1. **内容飞轮**：用户生产内容 → 内容吸引新用户 → 新用户生产更多内容。（例：小红书、B站）
2. **网络效应飞轮**：用户越多，产品对每个用户越有价值 → 吸引更多用户。（例：微信、闲鱼）
3. **推荐飞轮**：用户邀请好友 → 好友成为用户 → 好友再邀请。（例：拼多多、瑞幸）
4. **数据飞轮**：用户越多，数据越多，体验越好 → 吸引更多用户。（例：抖音推荐算法）

## 三、判断飞轮是否存在

问三个问题：
1. 现有用户会不会自发带来新用户？
2. 新用户来了之后，会不会提升现有用户的体验？
3. 这个循环是否能自我强化？

如果三个答案都是"是"，飞轮存在。

## 四、飞轮转不起来怎么办

- 如果没有自然增长机制，就只能靠付费增长，必须确保 LTV > CAC。
- 如果飞轮存在但转得慢，找到卡住的环节（通常是激活或留存）。
- 不要在没有飞轮的情况下盲目烧钱获客——钱烧完增长就停。

## 方法论要点

- 飞轮是增长的终极目标，但不是所有产品都能建立飞轮。
- 没有飞轮的产品也能赚钱，但增长有天花板。
- 判断飞轮的关键是：停止所有推广后，用户数还会不会自然增长。
