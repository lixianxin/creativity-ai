# 红线与一票否决

终审的硬门槛。任一红线命中，即不得直接准入路演；部分红线命中最高只能"有条件准入"，部分直接"暂缓"或"材料不齐"。

## 四条红线

1. **合规致命风险**：风险审查官结论为"存在致命风险，待处置"。
   - 处置：最高只能给"有条件准入"，条件必须是"红线清除并经风险审查官复审"。
   - 未清除前不得准入。

2. **红队致命问题未推翻**：红队结论为"暂缓通过"，且其致命问题未被更高优先级证据（真实业务数据）推翻。
   - 处置：最高只能给"暂缓，回到修改循环"。
   - 若被真实数据推翻，则降级为一般风险，不触发本红线。

3. **财务不成立 + 商业致命**：财务分析结论为"数字倾向不成立"，且红队同时存在致命商业问题。
   - 处置：不得准入，判"暂缓"。
   - 仅财务不成立但红队无致命商业问题，可走有条件准入。

4. **关键报告缺失**：财务分析、红队审查、风险审查任一缺失。
   - 处置：不给准入结论，判"材料不齐，不予终审"。

## 红线检查纪律

- **逐项核对**：每条红线必须明确写"有/无/未评审"，不得跳过。
- **一票否决不打折**：红线命中时，无论五维评分多高，结论不得为"准入路演"。
- **不替项目方清除红线**：只写清除条件（补什么证据/重跑哪个Agent），不设计新方案。
- **普遍待补证≠可路演**：无致命红线但五维大量3分、无行为级证据时，应判"暂缓"，不得放行。
