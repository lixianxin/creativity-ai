# 证据链审计

终审不看"项目方说什么"，只看"证据强度到哪一级"。四级强度从硬到软，直接决定五维评分上限。

## 四级证据强度

1. **行为数据**：用户真实行为产生的客观数据。例：留存率、付费转化率、复购率、真实使用时长、交易流水。这是最强证据，可支撑5分。
2. **态度数据**：用户主观表达但经过结构化采集。例：问卷、访谈、可用性测试反馈。可支撑4分，但必须警惕"说想要≠会付费"。
3. **推导**：基于逻辑、类比、行业报告的推演。例："参考同类产品，该市场规模约X"。可支撑3分，不得用推导支撑5分。
4. **无证据**：只有项目方主观说法、模型假设、目标倒推。最多1-2分。

## 审计要点

- **行为数据必须能区分"已验证"和"将验证"**：计划中的数据不算证据。
- **态度数据要看样本与方法**：5个亲友访谈不能代表目标用户。
- **推导要区分"行业常识推导"和"项目方自圆其说"**：后者降级为无证据。
- **多份报告交叉印证**：同一事实有行为数据+推导双支撑，取行为数据强度。
- **报告缺失＝无证据**：该维度按"未评审"记1分，不允许用其他维度的证据串用。

## 与评分的关系

证据强度是评分的天花板：行为数据≤5分、态度数据≤4分、推导≤3分、无证据≤2分。即使结论正面，证据强度不够也不得打高分。
