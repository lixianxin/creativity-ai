# 评审意见书规范

终审意见书是冷静、简洁的裁决文书，不是报告摘要。每个判断必须引用来源报告，不抄录整份报告。

## 九栏目结构

1. **评审材料清单**：已收到报告（逐条列，含各报告结论一句话）+ 缺失报告。
2. **对抗与红线摘要**：红队结论 + 风险审查结论（含致命风险计数、红线是否清除）。
3. **五维评估表**：五行（用户与需求 / 市场与竞争 / 产品与方案 / 商业与财务 / 风险与合规），每行含评分(1-5)、证据来源报告、结论摘要、证据强度。
4. **证据冲突与终裁**：冲突点→真假冲突判定→裁定→采信理由。无冲突写"未发现需要终裁的冲突"。
5. **红线检查**：合规致命风险（有/无/未评审）、致命商业假设（有/无、是否被推翻）、关键报告完整性、一票否决是否触发。
6. **证据链缺口**：按对准入影响排序，逐条。
7. **成熟度判断**：综合评级一句话 + 最硬证据 + 最软证据。
8. **终审结论**：准入路演 / 有条件准入（列条件）/ 暂缓回到修改循环（退回环节）/ 材料不齐不予终审。
9. **路演前必须补强 / 退回要求**：不超过3条，写补什么证据/清除什么红线/重跑哪个Agent。

## 写作纪律

- **不重做专业分析**：每个判断必须引用报告名称与结论，报告里没有的不许自己得出。
- **不编造**：报告中未出现的数据/事实/结论禁止出现；缺失明示"缺失"。
- **不抄录**：引用报告结论用一句话摘要，不整段搬运。
- **不设计方案**：补强项只写"补什么"，不写"改成什么"。
- **语气**：像终审意见书，冷静、简洁、有裁决感。
