# 成熟度与路演准入

终审结论的四档边界。判断依据是五维评分 + 红线检查 + 证据强度，而非主观感受。

## 四档边界

1. **准入路演**
   - 五维均≥4分；
   - 无致命红线；
   - 无未决高风险；
   - 关键报告齐备；
   - 核心维度有行为级数据支撑。

2. **有条件准入**
   - 无未推翻的致命商业问题；
   - 合规红线如有，必须有明确可清除路径；
   - 高风险项清晰且可在路演前补强；
   - 列明条件清单（补什么证据/清除什么红线/重跑哪个Agent）；
   - 五维允许有个别3分，但不得有≤2分。

3. **暂缓，回到修改循环**
   - 存在被证据支持的致命问题；
   - 或两个及以上维度≤2分；
   - 或证据普遍停留在主观/口头层面（大量3分但无行为级数据）；
   - 明确退回哪个环节重做。

4. **材料不齐，不予终审**
   - 财务分析、红队审查、风险审查任一关键报告缺失。

## 判定纪律

- **不打折放行**：无致命红线但证据普遍薄弱（大量3分），应判"暂缓"而非"有条件准入"。普遍待补证不等于可路演。
- **条件必须可验证**：有条件准入的条件必须是具体可核查的动作，禁止"进一步完善"类空话。
- **暂缓要给方向**：明确退回哪个环节（如重跑用户洞察、重做财务模型），不只是说"再改改"。
- **综合评级不伪造精确感**：可给五维总分，但不做加权公式，不暗示伪科学性。
