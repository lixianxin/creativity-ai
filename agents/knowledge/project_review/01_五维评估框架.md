# 五维评估框架

项目评审官做终审评分的底图。五维各1-5分，每个分数必须锚定报告结论与证据强度，不允许凭印象打分。

## 五维与证据来源

1. **用户与需求**：用户洞察报告为主，红队"用户/需求假设"攻击结论为对抗校验。
2. **市场与竞争**：市场分析报告 + 竞品分析报告，红队"竞争假设"为对抗校验。
3. **产品与方案**：产品设计报告，红队相关攻击为对抗校验。
4. **商业与财务**：商业模式报告 + 财务分析报告 + 增长运营报告，红队"商业/壁垒假设"为对抗校验。
5. **风险与合规**：风险审查报告为主，红队致命问题计入。

## 1-5分锚定标准

- **5分**：该维有报告明确给出正面结论，且有行为级/真实数据支撑。
- **4分**：报告结论基本成立，仅有少量待补证项。
- **3分**：报告结论为"部分成立/待补证"，方向可辨但关键证据缺失。
- **2分**：报告结论为"假设存疑/证据不足/倾向不成立"。
- **1分**：报告结论为"不成立/致命"。

## 特殊计分

- **报告缺失＝该维度"无报告支撑"，记1分并注明"未评审"**。不得脑补评分依据。
- 多个报告同向时取一致结论；多份报告冲突时走冲突终裁规则，不简单平均。
- 不得伪造精确权重科学感；综合评级只给整体判断，不做加权公式。
