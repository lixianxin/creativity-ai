# 冲突仲裁规则

多份报告结论不一致时，项目评审官做终裁。先辨真假冲突，再按证据优先级裁定。

## 第一步：识别假冲突

不同维度的结论看起来矛盾，实则可并存：

- 财务判"数字模型成立" vs 用户洞察判"需求未验证"——不矛盾。需求未验证时，财务模型不构成准入依据，但不代表财务计算本身错误。
- 市场分析判"市场大" vs 红队判"竞争壁垒弱"——不矛盾。市场大不等于项目能吃到。
- 产品设计判"方案完整" vs 增长运营判"渠道不成立"——不矛盾。产品好不等于卖得动。

判定假冲突的标准：两份报告回答的是不同问题。假冲突不需裁定，各自独立计分。

## 第二步：真冲突的证据优先级

同一事实出现相反结论时，按以下优先级采信（高＞低）：

1. 实际用户/业务数据（行为数据）
2. 专家分析报告（市场/竞品/产品等专业报告）
3. 财务计算
4. 红队审查结论
5. 模型推导
6. 项目方主观判断

## 裁定纪律

- **裁定必须写明**：采信哪份报告、为什么、被采信的证据强度是什么。
- **项目方说法优先级最低**：项目方陈述与任何报告冲突时，原则上采信报告，除非项目方能提供行为级数据反证。
- **不重做专业分析**：不自己重新算市场规模、不重新评竞品，只在已有报告间做取舍。
- **裁定后更新评分**：采信的报告结论直接影响该维评分。
