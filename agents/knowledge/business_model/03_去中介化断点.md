# 去中介化断点

去中介化断点是指商业模式中，平台价值可能被买卖双方绕开的那个环节。找到断点，才能判断模式是否可持续。

## 一、什么是去中介化断点

在双边交易中，当买卖双方通过平台完成首次匹配后，如果他们可以脱离平台直接完成后续交易，平台就失去了持续收入来源。这个"可被绕开"的环节就是断点。

## 二、识别断点的方法

画出完整的交易流程，在每一步问："这一步能不能不通过平台完成？"

典型交易流程：
1. 信息发布 → 2. 搜索/匹配 → 3. 沟通 → 4. 下单 → 5. 支付 → 6. 履约 → 7. 售后

- **信息发布**：可绕开（微信群、朋友圈）。
- **匹配**：可绕开（熟人介绍）。
- **沟通**：极易绕开（加微信）。
- **支付**：可绕开（转账）。
- **履约**：看是否需要平台参与。
- **售后**：可绕开（双方协商）。

## 三、防断点的策略

1. **资金托管**：钱必须走平台才有保障，绕开即失去保障。
2. **履约介入**：平台参与物流、质检、交付，绕开成本高。
3. **持续匹配**：每次交易都需要重新匹配（如外卖、打车），用户无法绕开。
4. **标准化供给**：买家信任平台胜过信任单个卖家。
5. **低频高客单**：虽然会被绕开，但单次抽佣足以覆盖获客成本。

## 四、无法防断点的应对

如果断点无法消除：
- 改为一次性服务费（匹配成功收一次）。
- 改为增值服务（基础匹配免费，增值服务收费）。
- 改为供给方付费（向卖家收流量费，不向交易抽佣）。

## 方法论要点

- 任何"匹配型"平台都必须回答去中介化问题。
- 断点不消除，规模越大损失越大。
- 防断点的核心是让平台在交易中承担不可替代的角色，而不仅仅是信息中介。
