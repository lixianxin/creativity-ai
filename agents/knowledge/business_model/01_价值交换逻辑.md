# 价值交换逻辑

商业模式的本质是价值交换：谁创造了价值、谁获得了价值、谁为此付钱。三者构成一个三角，缺一不可。

## 一、价值三角

```
        价值主张
        /        \
       /          \
    客户 ---------- 收入
```

- **价值主张**：你为谁解决了什么问题，提供了什么价值。
- **客户**：谁是你的用户（注意：用户不等于付费方）。
- **收入**：谁付钱、付多少钱、为什么付钱。

## 二、常见误区

1. **有价值主张，有客户，但没收入**：用户爱用，但没人愿意付钱。这是公益，不是生意。
2. **有客户，有收入，但价值主张模糊**：能收钱，但用户为什么付费说不清，不可持续。
3. **有价值主张，有收入，但客户不对**：价值给了 A，钱向 B 收，但 B 凭什么为 A 的价值买单？

## 三、价值交换的闭环

一个成立的商业逻辑必须回答：

1. 我为谁创造了什么价值？
2. 这个价值对方是否认可？（证据：用户行为、付费意愿）
3. 谁为此付钱？付费方是否直接或间接受益于这个价值？
4. 付钱的金额是否覆盖成本？

## 四、三方价值交换（平台型）

双边平台涉及三方：供给方、需求方、平台。价值交换更复杂：

- 平台为供给方提供：流量、订单、品牌背书。
- 平台为需求方提供：选择、信任、便利。
- 收入来源：抽佣、广告费、会员费、服务费。

## 方法论要点

- 不算金额，只画逻辑——先确认价值交换的方向是通的，再算数字。
- 如果价值交换链条中有任何一环断掉（比如付费方没有获得价值），模式不成立。
- 用户喜欢 ≠ 商业模式成立。成立的标准是有人愿意持续付钱。
