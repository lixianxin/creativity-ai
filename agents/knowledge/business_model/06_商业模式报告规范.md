# 商业模式报告规范

商业模式报告的核心产出是一张价值交换图和一个明确结论。不算金额，只画逻辑。

## 一、报告结构

### 1. 价值交换图

用图示说明：
- 价值从哪里产生
- 流向谁
- 谁为此付钱
- 钱流向哪里

图中标注每一方获得的价值和付出的成本。

### 2. 付费方分析

- 付费方是谁（具体角色）
- 付费方获得的价值
- 付费方为什么愿意付这个钱
- 付费意愿的证据（已付费 / 有意向 / 仅假设）

### 3. 去中介化断点分析

- 交易流程中哪些环节可被绕开
- 防绕开策略是什么
- 如果无法防绕开，收入模式如何调整

### 4. 闭环完整性检查

列出获客→使用→付费→交付→留存→复购每一环的现状和风险。

### 5. 结论

四档之一：成立 / 部分成立待补证 / 不成立 / 证据不足。

## 二、方法论要点

1. 价值交换图必须画清楚，不能只用文字描述。
2. 付费方必须是具体的人或组织，不能是"用户""客户"这种模糊词。
3. 去中介化分析不能跳过——只要是平台型业务，必须单独分析。
4. 结论必须明确，不能写"基本可行"这种模糊判断。
5. 不算具体金额（如年收入多少），只判断逻辑是否成立。
