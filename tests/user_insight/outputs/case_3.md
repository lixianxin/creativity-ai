# 用户洞察官案例3：考研自习室-有访谈证据-考证据质量识别

- 平台：deepseek / deepseek-v4-flash
- 耗时：45.3s，tokens：1656+4571

## 输入

项目名称：考研寄宿自习室预约与拼团平台
项目描述：我要做一个面向本校考研学生的寄宿自习室预约与拼团平台，已访谈120名备考学生，68人表示愿意每月付300元买固定座位，目前学校周边3家自习室空位靠微信群登记、经常抢不到，我打算先做微信小程序，向自习室抽佣10%。
目标用户：本校考研学生
核心痛点：自习室空位靠微信群登记、经常抢不到
解决方案：微信小程序预约+拼团
商业模式：向自习室抽佣10%
当前阶段：想法阶段（有120人访谈，无真实付费）

## 用户洞察输出

【用户洞察报告】

洞察结论：部分成立，待补证  
一句话依据：有120名本校考研学生“愿意每月付300元”的态度级证据，以及“微信群登记、经常抢不到”的行为描述支持痛点方向，但尚无一笔真实付费、没有供给侧自习室参与意愿的证据，证据链存在明显缺口。

一、用户画像清晰度  
- 项目方定义：“目标用户：本校考研学生”（原文）  
- 洞察：你定义的用户是“本校考研学生”，这一描述可识别、可触达（同校范围），但不可视为行为同质的用户画像。“考研学生”中既有固定去图书馆的应届生，也有需要全天稳定座位的往届二战生，自习频率、付费能力、对“固定座位”的需求强度都不同。更接近目标用户的应是与“3家自习室、微信群登记”直接相关的群体，但材料没有给出该群体的进一步特征，例如：当前是否已经在这3家自习室消费、每周来几天、有没有其他座位来源。

二、用户分层与种子用户  
- 核心用户 / 次要用户：  
  核心用户：本校考研学生中，备考期间需要高频、稳定、可预期的自习座位，且愿意为固定座位付月度费用的学生。  
  次要用户：偶尔需要临时座位、可接受拼团优惠的学生。  
  材料未提供区分依据，以上为基于场景的推断，待验证。  
- 可落地的种子用户假设：无法从材料中确定，待验证。一个可能的假设是：“学校周边3家自习室微信群里，已经有过多次抢座行为或已经购买月卡/次卡、备考周期在半年以上的本校考研学生”——但材料没有提供这类人群的获取渠道与占比。

三、使用者与付费者  
- 使用者：考研学生本人。  
- 付费者/决策者：考研学生本人支付每月座位费；自习室经营者向平台支付10%抽佣。  
- 分离风险：学生侧使用者和付费者同一，不构成断裂。但项目存在供给侧参与方：自习室经营者不是平台服务的使用者，却是平台商业模式成立的前提——他们是否愿意开放空位、接受预约、支付10%抽佣，目前完全未验证。用户研究只覆盖了学生侧，供给侧参与链存在明显未验证风险。

四、核心任务与痛点（JTBD）  
- 场景与任务：备考期间（尤其是座位紧张的时段），考研学生需要“稳定获得一个可长期使用的自习座位”，以便按计划进行每日复习。  
- 痛点频率与强度：“经常抢不到”提示频率似乎不低，但项目方没有量化——是每天抢不到、每周几次、还是某个时间段/高峰期才会出现？强度方面，抢不到座位可能引发绕路找座、打断复习、焦虑，但缺少用户原话或行为记录支撑，目前只能视为“待验证”。  
- 现有不满的具体内容：项目方只概括为“自习室空位靠微信群登记、经常抢不到”。具体不满可能是“群里消息刷得太快”“不知道还有没有座”“登记了却排不上”“好座靠手速”等，但材料未提供细节，这是当前缺口。

五、用户当前行为路径  
- 用户现在如何完成该任务：项目方描述为：“目前学校周边3家自习室空位靠微信群登记、经常抢不到。” 估计用户当前路径为：加入自习室微信群 → 等管理员发布空位/接龙 → 在群里登记 → 抢到或没抢到。  
- 这条当前路径是判断需求真实度的重要证据，但项目方提供的信息过粗：未说明微信群登记的具体规则、空位数量与群内人数、抢不到后的用户行为（去图书馆、换一家、当天放弃自习等）。这些细节目前缺失，属于关键缺口。

六、需求证据质量  
- 现有证据清单：  
  ① 访谈120名备考学生，68人表示愿意每月付300元买固定座位——按证据等级属于“弱态度（口头说愿意）”，非行为证据。  
  ② “3家自习室空位靠微信群登记、经常抢不到”——若来自项目方观察或道听途说，属于“主观判断”；若有微信群聊天记录、抢座失败次数等，则属于行为证据，但项目方未提供来源和统计方式。  
- 证据局限：  
  (1) 120名受访者的抽样方式未说明：是所有考研学生随机拦访，还是专门找正在抢座/购买自习室座位的核心用户？抽样偏差会直接影响“68人愿意付费”的可信度。  
  (2) 提问方式未披露：如果只问“你愿不愿意每月付300元买固定座位”，受访者容易给肯定答复，但口头承认不等于掏钱。  
  (3) 供给侧证据为零：没有访谈自习室经营者，没有证据证明自习室愿意接入平台并支付10%抽佣。  
  (4) “300元”的价格没有参照系：学生目前是否已经为座位付了费？300元比现有月卡高还是低？未提供。

七、用户维度关键疑点  
- “目标用户是本校考研学生”过宽：真正和“3家自习室微信群登记”相关的用户，远小于“全体考研学生”。若用全体考研生作基数去估算需求，会显著放大用户规模。  
- “68人表示愿意每月付300元”是口头意愿，不是付费行为；且在未筛选受访者是否已有付费自习需求的情况下，这个比例极可能是乐观估计。  
- “经常抢不到”没有被量化：是每天发生、每周发生、还是仅某个季节出现？没有频次数据的痛点，无法判断是不是“真实、高频、强烈”。  
- 供给侧无证据：自习室空位紧张是需求侧描述，但自习室是否愿意与一个第三方小程序合作、开放空位、并接受10%抽佣，未被验证。如果供给方不接入，预约平台无法实现。  
- 决策链存在一个隐性环节：学生愿意付费并不等于自习室愿意配合；即便学生侧需求真实，供给侧不配合，商业模式仍会断裂。

八、必须补充的用户研究（按优先级）  
① 加入并观察学校周边3家自习室的微信群，连续记录至少1—2周：每天放出多少空位、群内有多少人参与登记、多少人抢不到、抢不到的人接下来做了什么（是否离开/换地方/次日再抢）。这能把“经常抢不到”变成行为数据，并验证痛点频率与强度。  
② 从上述微信群中筛选30—50名真正参与抢座的学生，做一个行为级小测试：向他们提供一个“预付50元定金，预留固定座位一个月”的真实选项，看实际缴纳定金的比例。如果只有口头意愿而无定金行为，则需求应打折扣。  
③ 访谈3家自习室经营者（或管理员），至少各1人：当前微信群登记的具体流程、真实空位率、是否愿意接入第三方预约平台、能否接受10%抽佣。否则“向自习室抽佣10%”可能只是单方面设想。  
④ 对10—15名“最近一周内抢座位失败过”的学生做深度访谈，还原上一次抢座失败前30分钟到失败后的完整行为路径（群里的交互、失败后情绪、替代方案），补上对用户任务和真实不满的具体理解。
