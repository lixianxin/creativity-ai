# 用户洞察官案例1：二手书-画像过宽无证据

- 平台：deepseek / deepseek-v4-flash
- 耗时：103.8s，tokens：1601+10983

## 输入

项目名称：校园二手书交易平台
项目描述：我要做一个校园二手书交易平台，目标用户是全国大学生，平台从每笔订单抽取5%服务费，我预计第一年做到10万用户。
目标用户：全国大学生
核心痛点：未提供
解决方案：校园二手书交易撮合平台
商业模式：每笔订单抽5%服务费
当前阶段：想法阶段

## 用户洞察输出

【用户洞察报告】

洞察结论：证据不足  
一句话依据：项目方只提供了“全国大学生”这一统计口径，核心痛点未提供，也没有任何用户访谈、行为或支付证据；当前无法验证“用户与需求假设”是否成立。

一、用户画像清晰度  
- 项目方定义：“目标用户是全国大学生。”  
- 洞察：这不是用户画像，而是统计口径。“全国大学生”覆盖不同学历、年级、专业、院校层级和校区，实际行为可能高度异质：有人是大一新生要买公共课教材，有人是毕业生要卖旧书，有人可能根本不需要教材交易。不同人的购书场景、预算、时间节点和触达方式都不同。没有定义到“哪类学校的哪类学生、在什么场景下买什么书”，就无法识别、触达和验证。“二手书”本身也没有被界定是教材、教辅、考试资料还是课外书；不同书类的需求逻辑很可能完全不同。

二、用户分层与种子用户  
- 核心用户 / 次要用户：材料不足以支撑分层。你描述的用户是“全国大学生”，但方案是“交易撮合平台”，那么这个平台天然至少需要两类用户：有书要找的学生，以及有旧书要卖的学生。项目方没有说明优先服务买家、卖家，还是两侧同时起步。  
- 可落地的种子用户假设：无法从材料中确定，待验证。理想种子用户至少应具体到“某个学校×某类专业/年级×开学前需要特定教材的学生”，以及同一校园内结课后想处置教材的学生。同一个校园的交易场景和不同校园之间可能存在明显差异，不能直接以“全国大学生”作为统一种子池。

三、使用者与付费者  
- 使用者：项目方未说明。可推断为校内学生，但教材交易的触发者未必是学生本人。  
- 付费者/决策者：未提供。若交易直接发生在学生之间，付费者大概率是使用者；但如果一本书来自“老师指定的课程教材”，学生只是最终付款人，而需求的发起方可能是教师或课程体系。这个决策链在材料中空缺。  
- 分离风险：未提供。需要确认是否存在“学生使用并付费，但‘需要哪本教材’的决定权不在学生”的情况。

四、核心任务与痛点（JTBD）  
- 场景与任务：未提供。项目方没有说清楚：学生在什么时刻、为了完成什么任务，才需要一个“校园二手书交易平台”？  
- 痛点频率与强度：待验证。没有证据能说明买卖二手书的痛点多久出现一次、不解决会有什么实际损失，也没有用户表达过“现在的方式让我很痛苦”。  
- 现有不满的具体内容：未提供。没有来自真实用户的抱怨，比如“找不到某版本教材”“价格太贵”“交易太慢”等均未出现。项目方连“当前痛点”这一栏都没有填写，因此无法对痛点真实性下判断。

五、用户当前行为路径  
- 项目方未提供。这是关键缺口。学生现在如何获取和处理教材？是否已经在班级群、学生自发的二手群、学长学姐转让等渠道完成交易？这些路径是否免费且够用？这些问题不回答，就无法判断“交易平台”要取代或改善的到底是什么。若学生已有低摩擦、低成本的现有路径，那么用户为5%服务费买单的意愿会大打折扣。

六、需求证据质量  
- 现有证据清单：  
  1. “目标用户是全国大学生”——评级：项目方主观判断。  
  2. “预计第一年做到10万用户”——评级：主观目标，不是用户需求证据。  
  3. “核心痛点：未提供”——证据缺失。  
- 证据局限：项目方处于想法阶段，没有任何访谈、问卷、真实交易或行为数据；没有样本量；也没有可检验的提问方式。当前全部需求判断都来自项目方自身，未出现任何用户声音。

七、用户维度关键疑点  
1. “全国大学生”是统计口径，不是可识别用户群；若不能拆到具体校园、具体人群和具体教材场景，几乎无从切入。  
2. 平台定义是“交易撮合”，但你只描述了单边“全国大学生”，没有说明最先需要吸引的是买方还是卖方；双边市场中任一侧启动不了，另一侧也很难成立。  
3. 核心痛点未填写，意味着目前连“用户声称的痛点是什么”都没有，遑论验证其真实、高频、强烈。  
4. “第一年做到10万用户”是目标数字，不是行为证据。它不能说明已有多少种子用户愿意使用、付费或持续回来。  
5. 每笔订单抽5%服务费的用户接受度未被验证。如果学生现有交易渠道接近免费，哪怕5%本身不高，也可能成为用户不使用的理由——这不是财务判断，而是用户行为假设，需要真实交易测试。  
6. 用户决策链未描述。教科书使用场景下，很可能存在“学生购买但教师指定”的外部影响；若不追踪书单从哪来，可能会把“被迫买书的学生”误判成“主动选择二手书交易的人”。

八、必须补充的用户研究（按优先级）  
① 在2-3所不同城市/类型的高校，每校访谈20-30名学生，覆盖多个年级与专业。重点追问过去一年真实发生的买卖教材行为：买过什么书、通过什么渠道、花了多少钱、花了多长时间、哪个环节最麻烦。不要问“若有一个平台你是否愿意用”。  
② 在授权且合规的前提下，进入或联系一所目标学校已有的学生二手书交易渠道，记录一周内真实的求购/出售信息数量和成交情况，观察“撮合”是否真是当前缺口，还是信息已被现有渠道解决。  
③ 在一个具体学校开展小规模真实行为测试：不开发平台，仅人工撮合10名左右想卖书的学生与10名左右想买书的学生尝试完成真实交易；对部分成交收取5%服务费，比较收费版本与不收费版本的成交差异，获取用户是否愿意为这项服务真实付费的行为证据。
