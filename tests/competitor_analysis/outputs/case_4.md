# 竞品分析官案例4：自习室-供给方去中介化

- 平台：deepseek / deepseek-v4-flash
- 耗时：52.1s，tokens：1652+4848

## 输入

项目名称：本校考研自习室预约小程序
项目描述：我只做本校考研学生的自习室预约，学校周边有3家自习室，目前空位靠微信群登记、经常抢不到。已访谈120名备考学生，68人表示愿意每月付300元买固定座位。我打算先做微信小程序，向自习室抽佣10%。
目标用户：本校考研学生
核心痛点：自习室抢不到座位
解决方案：微信小程序预约
商业模式：向自习室抽佣10%
当前阶段：想法阶段（有120人访谈，未上线）

## 竞品分析输出

【竞品分析报告】

竞争格局总览：
当前“考研自习室座位”赛道在校内/校外周边呈现高度分散、超本地化的格局。没有全国性平台垄断，核心竞争发生在“线下物理空间运营方”与“低效的人工管理工具”之间。线上主要承载于微信群、小程序接龙等免费民生工具，线下则由3家自习室各自为政。竞争壁垒极低，属于“谁掌握了店主的排座权，谁就掌握入口”。

直接竞品：
- 本地/通用自习室预约SaaS系统（如“去K书”、“自习室管理系统”等）【候选，需核验】：其形态为向自习室店主提供智能预约软件，替代人工登记。与项目重叠点为“解决自习室预约”，但其主要服务对象是B端店主，项目本质也是做B端SaaS+抽佣，二者赛道重叠。
- 3家校内自习室自身可能使用的内部小程序/智能闸机【候选，需核验，项目方未提供】：若店方已有自用预约系统，项目将直接替代店方现有系统。

间接竞品：
- 学校图书馆/教务处官方座位管理系统（例如图书馆选座小程序【候选，需核验】）：用“免费、官方”的方法解决“占座/找座”需求，分走本校考研学生流量。
- 考研培训机构（如文都、新东方考研）【候选，需核验】：通过报班赠送“固定自习座位”来切割学生预算。
- 付费自习室竞争对手（同区域内其他校区而非本校的独立品牌）：解决同一“安静学习场所”问题，但不在本项目3家范围内。

替代方案（用户当前真实解法）：
- 微信群登记（项目方已披露，目前核心痛点来源）。
- 学委/群主手动Excel或腾讯文档表格登记。
- 线下物理到场占座（早起排队、放书占位）。
- 校图书馆免费自习室（须接受“占座痛点”和“可能闭馆”）。
- 教学楼空教室/咖啡店/食堂自习（“忍受现状”）。
- 学长学姐私下转让座位或熟人代抢。

用户当前解法与迁移成本：
当前微信群登记是“够用”的：零额外收费、零新平台注册、信息通知免安装、店主可实时群发。痛点“抢不到”是源于座位供给小于需求，而不是工具不够快。用户迁移（学生端）成本低：可能只需微信小程序点击，无需下载App。但真正的迁移阻力在于“B端老板”：商家需接受每单被抽取10%佣金，且需要从原有微信群人工管理模式切换出来。若店方只要把30元佣金退还学生并私下用群内转账，平台价值瞬间归零。迁移理由目前仅基于学生单方面“愿意花300元占座”的访谈，缺少“店方愿意放弃管理权且支付10%佣金”的证据。当前方案免费又具备熟人信任链，除非形成“一个学校内3家同时接入、且不接入就约不到座”的排他性，否则迁移理由不充分。

差异化分析：
- 项目声称差异点：只做“本校”考研学生，极度垂直本地；能提供固定座位预约。
- 证据状态：声称待验证。项目方未给出与“微信群登记/店主自有系统”的功能对照或体验差异数据；未访谈店方是否愿意支付10%佣金。
- 被复制难度：极低。微信第三方或自习室收银系统即可开发一个预约模块，甚至店主自己开一个“腾讯文档+接龙管家”加一个“付款占座”即能实现；若差异仅是“提供300元固定座预订”，那就只是一个支付通道，而非有壁垒的差异化。

竞争反应与去中介化风险：
- 最危险的竞争来自“现状”——微信群。店方一旦发现平台抽取10%，极容易通过拉新群、私聊转账，用“特价”或“免费周”引导用户回流到线下，将项目变为一次性导流工具，这就是彻底的“去中介化”。
- 大平台碾压风险小，微信小程序仅是一个前端；但腾讯文档、金山文档等免费表格即可实现“预约”，且不抽佣。
- 一旦验证该模式可行，本校区其他自习室（若新开）会直接自建简易系统；学校图书馆或教务处可能推出官方统一选座平台（目前已有部分高校实行），以免费官方身份介入，项目将失去“本地化独占性”。

关键竞争风险：
①供给侧（店方）是最大的竞争者：店方掌控物理座位与定价权，抽佣10%会诱导其跳单、自建或维持微信群，本项目极易被绕开。
②免费替代方案（微信群+Excel）已经在运转，且零成本。只有在“抢不到”发生后，用户才会想起工具，但抢不到的根因是“供给太少”，系统无法增加座位。
③交易并非在平台上闭环：项目仅做“预约”，无法验证学生是否真到场、是否私下给店主付款；一旦无法闭环，抽佣模式（10%佣金）将被证明只是幻觉收入。

证据缺口：
①缺少对3家自习室店主的访谈或书面确认：是否接受300元/月售价？是否愿意向第三方支付10%佣金？店主目前微信手动登记空位分配的真实运营痛点是什么？
②缺少全国/本地“同形态竞品”名单核实：项目方未给出其对自习室预订平台的真实调研数据；需核实3家门店是否已接入正规预约系统，而非仅靠微信群。
③缺少现有“微信群登记抢座”的失败数据：120名学生访谈中，是否有具体记录“多少次未抢到”、“错过通知后怎么办”；若无数据，则不能证明用户痛点强到愿意额外付费30-300元迁移到新工具。

竞品结论：
部分清晰，待补证

建议验证：
①直接前往这3家自习室，以普通用户身份实测“店面预约”流程，观察其是否有纸质签到表、微信群管理员是店主本人还是付费员工；访谈店主：目前满座率、退订率、是否愿意为了未来扩大流量承担10%佣金（提示其可接受上限）。
②用“模拟报名页”或“假排名”进行一次小规模灰度测试：在考研社群发布“为了保障座位，从下周起需通过小程序（测试版）报名，且需支付定金”的通知，看有多少学生完成支付转化；同时测试店主若需要把收银权迁移给第三方时的配合意愿。
③找出本校/附近3公里内其他已实现高校图书馆座位预约的官方系统，进行“官方0佣金、可验证校内身份”的对照，检验这是否会直接吞掉“本校考研学生”这一客群。
