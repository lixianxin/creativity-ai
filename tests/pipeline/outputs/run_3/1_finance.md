# Run3 财务分析输出

## 输入
项目名称：本校考研寄宿自习室预约与拼团平台
项目描述：我要做一个面向本校考研学生的寄宿自习室预约与拼团平台，已访谈120名备考学生，68人表示愿意每月付300元买固定座位，目前学校周边3家自习室空位靠微信群登记、经常抢不到，我打算先做微信小程序，向自习室抽佣10%。
目标用户：本校考研学生（项目方原文）
商业模式：向自习室抽佣10%；学生付自习室约300元/月
当前阶段：想法阶段（有120人访谈，无真实付费/试点数据）

## 输出

【财务可行性分析报告】

分析结论：数字倾向不成立
一句话依据：项目方提供的“抽佣10%”成立的前提是“钱经过平台”这一交易闭环，但根据项目描述（学生直接付给自习室“约300元/月”），该闭环大概率不成立，抽佣收入基数为0或无法确认；且以3家自习室可提供的物理座位总量为天花板，即使假设全部满座，月GMV也仅为数万元，10%佣金月收入最高仅几千元量级，无法覆盖任何含人力的基础运营成本。

一、数据盘点
- 项目方已提供：
  1. 访谈120名备考学生，68人表示愿意每月付300元购买固定座位。
  2. 周边3家自习室，空位靠微信群登记，经常抢不到。
  3. 拟做微信小程序，商业模式为向自习室抽佣10%（学生付自习室约300元/月）。
- 关键缺失（待验证）：
  1. 交易是否在平台内闭环完成（能否强制分账）——这是抽佣收入的生死前提。
  2. 3家自习室的实际总座位数、当前入住率、月轮换率（有多少人退座）。
  3. 平台开发/维护成本、运营人力成本、获客渠道成本。
  4. 自习室是否真的愿意接受“被抽佣”，是否会直接绕过平台成交（微信群已有此功能）。

二、收入模型拆解
- 付费方：学生（付费给自习室，非平台）；平台拟向自习室收佣金。
- 收入来源与计费方式：交易佣金 = 学生实际支付年度流水 × 10%。
- 单笔/单用户年收入推导：
  公式：平台年抽佣收入 = 自适应室通过平台产生GMV × 10%
         = 通过平台成交的座位数 × 月租300元 × 12个月 × 10%
  代入（项目方未提供实际平台成交数，仅能给出假设值）：
  - 若按3家自习室每家平均200个座位【假设值（待验证）】，总座位数600个；
  - 极致乐观情况下，所有座位每月都被通过平台预订并支付，全年满租：
    年GMV = 600个座位 × 300元/月 × 12个月 = 216万元人民币
    平台年抽佣 = 21.6万元人民币。
  但该结果建立在以下硬性条件之上：
  - 交易完全经由平台收付，没被微信群/线下绕过（项目方未提供证据）；
  - 600个座位每月100%周转、100%通过平台支付、无场外私下转租（现状是人工登记、抢不到，说明无任何技术分账）。
  在无真实闭环的前提下，依【铁律#7】抽佣收入按“无法确认，暂计为0”处理。

三、单位经济
- 客单价：学生端单座300元/月【项目方提供】。
- 交易频率：按年续费12次为上限，但周期内无新增消费。
- 毛利率：无法可靠计算（无平台成本数据）。
- CAC：无法可靠计算（项目方未提供任何获客成本或渠道支出）。
- LTV：公式 = 月平台收益 × 留存月数 / 座位数。即使满租：单座位年平台收益 = 300 × 10% × 12 = 360元/座（按项目方满租假设计算，未验证）。
- CAC回本周期：无法计算。小程序需扫楼/社群/地推等动作，项目方未提供任何CAC金额或运营预算。

四、成本结构
- 固定成本：待验证。至少包含：
  - 微信小程序认证费300元/年（已知常规平台成本，非项目方数据，视为基础假设值（待验证））；
  - 服务器及云资源（假设初期100-300元/月【假设值（待验证）】）；
  - 若允许支付分账需第三方支付/分账系统费率（通常0.6%-1.2%通道费【假设值（待验证）】）；
  - 人工运营（至少要有一个专职地推/客服，按最低单位人力成本也是数千元/月【假设值（待验证）】）；
  - 维护方研发费用（外包或自研，项目方未提及，假设数千至数万元一次性【假设值（待验证）】）。
- 变动成本：支付通道费、地推物料、客服时间，均待验证。

五、盈亏平衡（BEP）
- 公式：BEP(月度座位需求) = 月度固定成本 / (300元/月 × 10%)
- 代入：由于固定成本项目方未提供，只能给出参考：
  若月度固定成本仅算1人最低合伙人成本5000元【假设值（待验证）】 + 服务器300元 + 通道费忽略不计 = 5300元/月，
  BEP(需通过平台支付满租的座位数) = 5300 / 30 ≈ 176.7个座位，即需要约177个固定座位每月经由平台实付才能保本。
  该项目仅3家自习室，且常常“抢不到座位”本身就暗示需求已跑在供应前，供给端就无增量座位，这177个座位大概率要挖走现有微信群用户。
  结论：在无增量座位供给的前提下，打平只能靠撬动原有的线下/微信群交易，且还需克服抽佣逃费问题，难度极高。

六、三情景分析
所有非项目方参数均标注“假设值（待验证）”。
| 参数 | 悲观 | 基准 | 乐观 | 来源 |
|---|---|---|---|---|
| 3家自习室可交易座位总数 | 300个 | 500个 | 600个 | 假设值（待验证） |
| 通过平台月支付用户占比 | 10% | 30% | 60% | 假设值（待验证） |
| 月GMV | 9000元 | 45000元 | 108000元 | 计算得出 |
| 平台月抽佣收入 | 900元 | 4500元 | 10800元 | 计算得出 |
| 月固定成本(含1位创始人全职机会成本) | 8000元 | 8000元 | 8000元 | 假设值（待验证） |
| 月净利润/亏损 | -7100元 | -3500元 | +2800元 | 计算得出 |
-   **结论**：在该模型下：
   -   *乐观情景*（600个座位全部被平台捕获且60%用户按月在线实付，无流失）的月净利也仅约2800元——不足一个兼职月薪。
   -   *基准情景*显示无法覆盖基础运营成本。
   -   *悲观情景*为净亏。
   但请注意：以上所有情景先假设“交易闭环成立”，即平台能强制收取10%佣金。若闭环不成立【铁律#7】，则上表所有收入直接归0，情景无意义。

七、压力测试
-   若佣金比例被自习室压价至5%【假设值（待验证）】：乐观情景月收入降至5400元，无法覆盖基础成本。
-   若座位实际只有300个，且月流失20%：乐观情景实际付费座位 ≈ 300×60%×(1-20%) = 144个 → 月佣金收入 = 1440元，严重亏损。
-   若一半座位由自习室与线下老客户私下续费，无法被平台监测或拦截：平台可计费座位再减半，分账收入缩水50%以上。
-   结论：关键变量恶化后果为营业收入跌破千元级，直指系统性失败。

八、现金流与资金风险
-   前期投入：待验证（小程序外包初期约几千至数万元【假设值（待验证）】）。
-   烧钱速度：由于无收入支撑，靠创始人垫资或外部资金维持，大概率每月净流出数千元以上【按基础人力假设推算】。
-   风险点：投入一旦开始即沉没——若3家自习室拒绝接入“强制在线支付分账”，平台完全无抓手，资金将彻底归零。

九、财务致命问题 / 高风险项
1.  **交易闭环不成立风险（致命）**：项目方描述“学生付自习室约300元/月，平台向自习室抽佣10%”。但自习室自己是收款方，相当于平台向线下商户收“保护费”，却无法保证交易不发生在微信群/线下。项目方未给出任何分账、堵漏或约束机制。
2.  **收入天花板极低**：按3家自习室，即使满座且全部被平台捕获，年毛收入上限约21.6万元（未扣任何成本），远不足以支撑一个小型团队或全职创始人。
3.  **缺乏交易增量证据**：访谈中“68人愿意付300元”只是付费意愿信号，不等于平台能为自习室创造新收入。自习室在没有新增收入的期待下，没有商业动机交10%佣金。
4.  **假设值严重依赖物理座位限制**：这是一个供给极其有限的本地低频服务，没有网络效应或复购放大机制。
5.  **获客成本/运营成本完全空白**：项目方处于想法阶段，无真实付费转化率、无获客预算、无团队薪资预算，任何收入测算都无法脱离“假设值”完成。

十、必须补充的财务数据（按优先级）
①    **交易闭环数据**：自习室目前如何在微信群收钱？你能否控制/代为收取租金，并从中扣除10%？如果不能，请给出你能强制分账的技术或法务方案（否则抽佣计为0）。
②    **3家自习室的座位总数、当前入住率、月度退座换新人次轮转率**（用于测算可被平台捕获的真实增量交易池）。
③    **3家自习室的营业利润率和提佣意愿**：每家是否愿意把你作为线上唯一入口？如果只做补充渠道，它们凭什么付你10%？
④    **启动成本和月度固定开销**：开发外包报价、服务器、人力工资、线下地推预算等。
⑤    **复购/续费数据**：考研座位使用周期是否仅为6-12个月？毕业后该生彻底流失，LTV是否被高估（考研学生最多使用2年，大概率只有1年内）？
