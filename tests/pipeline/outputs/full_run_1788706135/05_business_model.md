## 输出

【商业模式分析报告】

一、商业模式概述
- 模式类型：B2B2C 工具型 SaaS（本质是面向高校的 B 端收费产品；学生是 C 端免费使用者），外加一个尚未成立的“脱敏数据服务”收入假设。
- 核心价值交换：学生免费使用多智能体 AI 审查并获得结构化建议；高校为“把 AI 审查嵌入创业课程教学、大创项目筛选、创业大赛初赛评审”的批量管理能力，按年支付机构版费用。项目方同时收集学生提交的项目内容与报告数据，计划未来对外出售脱敏数据，但该付费关系尚无明确对象。
- 商业闭环：
  学生提交创业想法 → 多智能体 AI 生成审查报告 → 学生在课程/赛事场景持续使用 → 学校需要批量组织与筛选 → 创业学院/学校预算决策者付费 → 项目方获得年费收入 → 新一学期、新一批学生、新一轮赛事再次触发使用 → 续费/扩展。
  目前的关键问题是：尚未出现真实付费；老师口头感兴趣不等于学校预算决策者愿意付钱；免费个人版可能与学校机构版发生价值冲突。

二、角色关系
- 使用者：
  1. 学生：提交创业想法并获得 AI 审查报告；
  2. 教师/创业学院管理人员：可能使用机构版管理班级、批量查看报告、筛选大创项目、辅助初赛评审。
- 付费方：
  学校/创业学院，而不是学生。学生是免费使用者。
- 决策者（谁决定付钱）：
  真正的付费决策者应是创业学院院长/分管教学领导、教务处或学校采购/预算负责人。材料中的“创业学院老师口头感兴趣”不等于预算决策，只能算提出需求的信号。
- 服务提供方/供给方：
  项目方提供多智能体 AI 审查报告及机构版管理系统；底层大模型能力来自 API 服务商；学生也是内容供给方，因为平台会收集其提交的创业项目数据。
- 平台角色：
  希望成为高校创业教育流程中的“批量评审+筛选工具”。但当前“不可替代性”尚未被证明：学生个人可以免费获得报告，学校为什么一定要买机构版，取决于机构版是否掌握课程管理、大创筛选、竞赛初赛等流程入口。

三、价值主张
- 对使用者（学生）：
  免费获得多智能体 AI 专家委员会的结构化质疑与修改建议，帮助完善创业想法。
- 对付费方（学校/创业学院）：
  缓解创业指导师资不足，为创业课程、大创项目筛选、创业大赛初赛提供可批量复用的 AI 评审；学校买到的可能不是“学生可用 AI”，而是“本校教学/评审流程与管理后台”。
- 对供给方/合作方：
  对底层大模型 API 提供方而言，平台是调用方，但商业关系是采购关系，不属于平台式“供给方分红”结构。

四、付费逻辑
- 谁付钱：
  高校创业学院/学校，以年度机构版形式付费。
- 为什么付（买到的具体价值）：
  学校不是为学生能拿到报告而付钱，而是为“老师能在平台上布置任务、管理多个创业团队、批量获得结构化评审、并在大创筛选、创业大赛初赛等流程中使用统一标准”而付钱。
  如果学校老师只是让学生去公共免费版使用并自行查看报告，学校就没有必要采购机构版。
- 什么场景下付（付费触发点）：
  在教学计划启动前、大创项目申报筛选窗口、创业大赛校赛初评筹备阶段，需要把 AI 评审嵌入学校正式流程时付费。
- 付费假设是否有证据：
  付费假设待验证。材料只显示“2 所学校创业学院老师口头表示感兴趣”，没有真实合同、没有付款、没有进入学校采购流程，也未证明老师有能力决定预算。

|---|---|---|---|---|

六、商业交易链
- 用户需求：学生有创业想法，希望获得专业质疑；学校有课程教学、大创筛选与大赛初评的批量需求。
- 价值提供：学生免费获得 AI 审查报告；学校机构版提供批量管理等价值。但机构版与免费版的价值边界尚未清晰。
- 交易发生：尚未发生。学校是否采购取决于机构版是否成为教学/筛选/初赛的必要工具。
- 项目方获得收入：目前无实际收入来源。
- 用户获得持续价值：新一学期有新生、新一轮大创项目申报、每年创业大赛，存在重复使用的可能，前提是老师愿意持续把平台纳入正式工作流。
- 复购/续费：需要验证学校在一年使用后是否会续费，而不是只作为一次性采购或一次性试点。
  【商业闭环断点】当前交易断在“学校真实付费”环节。老师口头关注不是付费，免费公共版也可能让学校绕开机构版采购。

七、获客与转化逻辑
- 用户从哪里来：
  学生来自高校创业课程、大创项目群体、创业大赛参赛团队；学校机构版的获客入口是创业学院老师、课程负责人。
- 如何认识产品：
  可能通过老师布置任务、创新创业学院介绍、赛事说明会或学校正式采购流程认识。
- 为什么尝试：
  学生尝试成本低，因为免费；老师愿意尝试的原因可能是解决师资不足或赛事初评压力。
- 为什么第一次付费：
  只有当学校发现“不用机构版就无法方便地完成批量筛选、班级管理、流程留痕、初赛统一评审”时，才会付费。个人免费版越能满足这些需求，学校付费动机越弱。
- 为什么继续使用/复购：
  因为教学与赛事是周期性活动，新学生、新创业项目、新一届大赛会反复出现。但前提是平台被纳入学校正式流程，且老师形成使用惯性；否则复购逻辑会断。

八、商业模式风险
- 付费方识别风险：
  学生是使用者却不是付费方；学校是付费方，材料中的“老师口头感兴趣”也不等于学校预算愿意付费。若一直围绕学生免费体验做增长，却找不到学校预算入口，商业模式会落空。
- 付费意愿风险：
  老师的痛点可能是“缺指导老师”，但学校是否愿意为一个 AI 审查工具单独付年费，取决于该工具是否能替代/显著优化教师工作，而不是“学生喜欢用”。
- 转化风险：
  从免费学生版到付费学校机构版之间缺乏必然转化路径。如果老师可以直接让学生使用公开免费版并截图/链接提交，则学校没有足够理由购买机构版。
- 平台依赖风险：
  平台基于大模型 API 搭建，底层能力不专属于平台。如果学校或创业学院未来直接用通用大模型工具完成类似任务，平台的价值会下降。平台需要靠“流程嵌入+教学管理+赛事评审结构化标准”建立绑定。
- 去中介化风险：
  平台本质上处在“学生项目内容”与“学校评审需求”之间。如果学生提交的项目内容和 AI 报告不锁在平台内，老师可以通过公共免费版或者把报告导出后自行管理，平台就可能被绕过。
- 免费替代风险：
  学生免费用产品本身是一把双刃剑。如果免费版已经覆盖了课程使用与报告生成，学校为什么还要买机构版？必须明确免费版与付费机构版的边界，否则免费价值会吞噬付费价值。

九、关键商业假设
1. 高校创业学院/学校真的有可用于采购机构版软件的预算，且决策者愿意为“AI 创业项目审查与流程管理”付款。
2. 老师愿意在每个学期/每届大创申报/每届赛事初赛时，把平台作为正式工作流程，而不仅是偶尔试用。
3. 机构版价值与学生免费版价值之间有清晰边界。没有边界，学校会在免费版中完成同样任务。
4. 学校需求是周期性的，因此年费订阅具有续费基础；新学生、新项目、新赛事会持续产生使用需求。
5. “脱敏数据服务”存在真实付费方，并且该付费方愿意为学生创业项目内容与 AI 审查报告数据付费。目前这一假设没有付款对象、没有使用场景，应视为未验证。

十、最小商业验证
- 验证对象：
  高校/创业学院是否真实付费购买机构版，而不是只停留在老师口头感兴趣。
- 验证方式：
  从两所表现兴趣的学校中至少找一所，把“口头兴趣”推进为有付款义务的小范围采购/试点协议或真实预付款，覆盖一个完整学期或一次大创/创业大赛初赛周期；涉及的预算申请必须由学校采购/创业学院决策链发起，而不能只是老师口头认可。
  同时注意不要用“问卷式愿不愿意付”，而要观察真实的预算流程、合同与付款动作。
- 核心观察：
  1. 学校是否在正式采购流程中愿意付款；
  2. 老师是否让学生在平台内完成项目提交与 AI 审查，而不是只用公共免费版；
  3. 一个周期结束后，学校是否主动提出下一个学期/下一个赛事的续费或扩展使用。
- 通过条件：
  至少一所学校完成实际付款，并将产品排入下一学期的教学/评审流程；如果学校选择继续使用公共免费版而不付费，则说明现有付费价值边界不成立。

十一、商业模式结论
商业闭环部分成立，待补证。

理由是：学校作为付费方、学生作为使用者的角色结构可以画出，“学校为批量 AI 评审与流程管理付费”的价值交换逻辑也存在基本合理性。但目前闭环尚未真正闭合：没有真实付款，老师口头兴趣不等于预算决策者愿意付钱，免费学生版与学校机构版之间的价值边界也还不清楚。脱敏数据服务没有明确付费方，不能作为支撑商业闭环的收入来源。整体模式需要先完成“一所学校真实付费并使用一个完整周期”的最小验证。
