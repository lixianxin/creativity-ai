## 五、盈亏平衡（BEP）

设：

- \(P\)：单校机构版年费
- \(X\)：付费学校数量
- \(Q_s\)：单校一年产生的 AI 审查次数
- \(Q_f\)：免费用户一年产生的 AI 审查总次数
- \(c\)：单次 AI 审查的 API 变动成本
- \(C_f\)：年固定运营成本
- \(C_{acq}\)：年度销售/获客成本
- \(R_{data}\)：数据服务年收入，当前未确认，暂按 0 处理

收入 ≥ 成本的条件为：

\[
P \times X + R_{data} \geq C_f + C_{acq} + c \times (Q_s \times X + Q_f)
\]

可推导出打平所需付费学校数：

\[
X^* = \frac{C_f + C_{acq} + c \times Q_f - R_{data}}{P - c \times Q_s}
\]

这个公式还隐含一个硬条件：

\[
P > c \times Q_s
\]

也就是说：**单校年费必须大于单校一年带来的 AI 审查变动成本**，否则卖得越多亏得越多。

但由于：
- \(P\) 未提供；
- \(c\) 未提供；
- \(Q_s\) 未提供；
- \(Q_f\) 未提供；
- \(C_f\) 未提供；
- \(R_{data}\) 未确认；

**当前无法计算盈亏平衡点。**  
以上不是结论，而是项目方需要补齐后才能代入计算的公式。

## 七、压力测试

目前没有基准数字，所以无法进行具体数值压力测试。  
可先保留以下关系：

### 1. 免费用户规模增加
如果学生免费使用无限制，公式中 \(Q_f\) 上升：

\[
X^* = \frac{C_f + C_{acq} + c \times Q_f}{P - c \times Q_s}
\]

即：**免费用户带来的 AI 调用越多，需要付费学校数量越多，才能补回这个现金黑洞。**

### 2. 单校 API 成本上升
如果 \(Q_s\) 或 \(c\) 上升，分母 \(P - c \times Q_s\) 变小，甚至可能变为负数。  
一旦 \(c \times Q_s > P\)，则单校合同本身毛利为负，销售越多亏损越多。

### 3. 机构版降价 30%
需要知道原价 \(P\) 才能计算新的边际贡献。  
目前 \(P\) 缺失，无法代入。

### 4. 签约转化率下降
现有唯一信号是“2 所学校老师口头感兴趣”。  
如果最终付费学校数为 0，则收入为 0，而固定成本和 API 成本仍然存在。

**结论：压力测试无法完成，缺上述关键参数。**
