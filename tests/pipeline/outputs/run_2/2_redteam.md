# Run2 红队审查输出

## 输入
我要做一个校园AI产品，具体功能还没想好，但我觉得市场很大。

## 输出

【红队审查报告】

审查结论：暂缓通过

致命问题：5个  
高风险问题：0个  
一般问题：0个  

核心漏洞：

①【用户假设｜致命】  
- 攻击：你声称要做“校园AI产品”，但“校园”不是用户画像；学生、教师、行政人员、校友的需求完全不同。你又补了一句“具体功能还没想好”，这意味着你连“用户要在什么场景下完成什么任务”都没有界定。没有目标用户，任何获客、访谈、付费验证都无从开始。信息不足，当前无法判断。  
- 待验证：首批目标用户具体是哪个角色、哪个学校/场景、哪个年级或部门？你准备从哪里找到第一批种子用户？

②【需求假设｜致命】  
- 攻击：你原话是“具体功能还没想好”。这等于你还没有定义要解决的问题。你又说“我觉得市场很大”，但“市场大”是结论，不是需求证据；不能证明有人需要你的产品，也不能证明他们愿意改变现有行为。没有功能，就没有可检验的需求假设。信息不足，当前无法判断。  
- 待验证：你观察或访谈过多少个目标用户？他们现在用什么方法解决对应问题？痛点发生频率、强度以及现有方案的不满体现在哪里？

③【竞争假设｜致命】  
- 攻击：你只给了“校园AI产品”这个赛道词，没有说明产品形态和应用场景，所以我无法定位你的直接竞品、间接竞品或替代方案。你没有给出用户为什么从现有方案迁移到你这里的理由。“市场很大”反而意味着现有解法或替代方案很可能已经很多。信息不足，当前无法判断。  
- 待验证：当你的产品具体形态确定后，用户目前正在使用的替代方案是什么？它们最大的不足是什么？迁移到你的方案带来的额外收益或降低的成本是什么？

④【商业假设｜致命】  
- 攻击：你说“我觉得市场很大”，但没有说明谁付费、为什么付费、收入来源是什么、获客成本大概多少。没有这些，单位经济模型无法构建。“市场很大”与“能赚钱”之间没有推导链。信息不足，当前无法判断。  
- 待验证：付费方是用户、学校、家长还是第三方？预计客单价、交易频次、获客成本、毛利是多少？哪怕只是假设值，也要给出推理过程。

⑤【壁垒假设｜致命】  
- 攻击：你尚未定义任何具体功能、数据闭环或网络效应机制。“校园AI产品”加上“市场很大”不构成壁垒；它只会说明这个方向会吸引更多人竞争。你没有给出任何防止巨头、学校官方或同类创业公司快速复制的理由。信息不足，当前无法判断。  
- 待验证：如果产品最终成立，你计划形成的壁垒是哪一种：技术、数据、网络效应、渠道、品牌还是转换成本？形成这个壁垒需要多久？

证据缺口：
- 产品定义：具体功能、使用场景、交付形态（App/小程序/网页/硬件/服务等）未提供。
- 用户画像：未提供首要用户群及首批种子用户来源。
- 需求证据：未提供访谈、问卷、观察或任何求助记录。
- 替代方案清单：未提供用户目前已在使用的工具或人工方法。
- 竞争格局：未提供直接、间接、替代竞品名称及对比维度。
- 商业模式：未提供收入来源、付费方、定价、获客成本与成本结构。
- 增长推导：未提供从“市场很大”到用户量目标的渠道与转化逻辑。
- 壁垒来源：未提供团队资源、技术、数据、渠道或网络效应上的可防御基础。
- “市场很大”的依据：未提供市场规模数据、行业报告引证或可验证的推理。

必须回答的问题：
①你想让哪一类用户完成一件什么任务？为什么这件事需要AI，而不是普通工具、微信群或线下服务？
②你实际接触过多少个这类用户？他们现在为这个问题已经花了多少时间、精力或钱？他们最不满意的是什么？
③这个任务场景里，目前有多少种替代方案（包括免费、非AI、线下方式）？这些替代方案分别差在哪一点，才让你觉得必须做一个新产品？
④产品上线后谁愿意付费？付费方是目标用户，还是学校/机构/第三方？你判断他们愿意付费的证据是什么？
⑤如果要做到首批1000个稳定用户，你打算通过什么渠道获客？每个渠道预计转化率多少？这个推导依据是什么？

修改方向：
- 必须从“校园AI产品+市场很大”收敛到一个具体的用户、任务、场景组合，并先用非AI方式验证该任务是不是真痛点。
- 必须提供目标用户访谈或行为证据，不能再用“我觉得市场很大”替代需求验证。
- 必须盘点现有替代方案，说清楚用户迁移的明确理由。
- 必须补上收入来源和获客成本的粗略模型，否则无法判断商业可行性。
- 必须说明计划形成的壁垒类型与形成周期，否则在当前描述下不具备可防御性。
