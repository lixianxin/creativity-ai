# Run1 红队审查输出

## 输入
我要做一个校园二手书交易平台，目标用户是全国大学生，平台从每笔订单抽取5%服务费，我预计第一年做到10万用户。

## 输出

【红队审查报告】

审查结论：暂缓通过

致命问题：2个  
高风险问题：3个  
一般问题：0个  

核心漏洞：

①【用户假设｜高】  
- 攻击：你声称“目标用户是全国大学生”，但“全国大学生”只是一个统计标签，不是可启动的用户画像。大学从本科到专科、从大一到大四再到研究生，教材版本、购书节奏、预算、购买半径完全不同；更重要的是，你做的是一场双边交易，至少需要区分卖书学生和买书学生。你既没定义首批卖家人群，也没定义首批买家人群，甚至没说从哪一座城市、哪一所学校开始冷启动。没有种子人群，就没有办法验证产品功能、获客成本或供给密度。  
- 待验证：首批试点学校/年级/专业；该校区二手书供给与需求密度；首批卖方与买方从哪里来、各有多少。

②【需求假设｜致命】  
- 攻击：你声称做“校园二手书交易平台”，但你没有给出任何需求证据。大学生现在已经有大量二手书交易替代方案：闲鱼、转转、学校闲置群、表白墙、毕业季跳蚤市场、学长学姐直接转让/赠送等。这些方式往往零佣金、带本地信任、成交直接。你要么需要证明这些方案在某个真实场景中明显失效，要么证明用户愿意为了你的平台放弃现有渠道并承担迁移成本，但你没有给出访谈人数、试点数据、用户表态或任何可复核记录。“学生有二手书交易需求”不等于“学生需要一个新交易平台”。你当前的需求假设无证据，这是致命问题。  
- 待验证：目标学生最近一次买/卖二手书使用了什么渠道；他们对现有渠道的具体不满；多少人表示愿意迁移到抽佣5%的新平台。

③【竞争假设｜高】  
- 攻击：你声称“平台从每笔订单抽取5%服务费”，而用户现在最常用的替代方案中，闲鱼、微信群、跳蚤市场等很可能不向交易双方收5%服务费。你要求用户在真实交易中多付一笔成本，就必须给出足够强的迁移理由，但你没有说明你和这些零成本渠道之间的差异。另一个竞争问题是：大学教材天然有本校、本专业属性，在校内向师兄师姐买书往往比通用二手平台更高效率；如果你做的是通用市场，就直接进入与闲鱼/转转等现有平台竞争；如果你做的是局部封闭市场，你又必须解释未来如何突破单一校园并应对学校官方或校内学生组织自建渠道的威胁。这些目前都没有答案。  
- 待验证：目标用户当前首选的二手书交易渠道及占比；用户迁移到你的可测试意愿；如果闲鱼或学校官方做同类功能，你的应对依据。

④【商业假设｜致命】  
- 攻击：你声称“平台从每笔订单抽取5%服务费”并“第一年做到10万用户”，但商业模式模型完全缺失。第一，5%服务费没有说明是向买家收还是向卖家收，也没有证明任何一方愿意承担；第二，二手书订单客单价和交易频次未提供，若订单金额低、一年只有开学/毕业少数几次，单笔5%佣金非常低，可能覆盖不住获客、开发、运营、地推、客服和支付成本；第三，“10万用户”不等于“10万笔交易”，更不等于“10万有效佣金收入”，没有用户获取渠道×转化率×成本×时间的推导链。你没有给出CAC、LTV、客单价、交易频次、毛利、固定成本、变动成本，因此单位经济在当前描述中不成立。  
- 待验证：买卖双方谁支付5%；平均客单价区间；年均交易频次；用户获取成本CAC；用户生命周期价值LTV；第一年10万用户的渠道推导公式。

⑤【壁垒假设｜高】  
- 攻击：你只描述了“校园二手书交易平台”这个产品形态，没有提出任何不可复制的壁垒。二手书平台不拥有独家商品，也没有垄断供给侧；现成电商/社区功能很快可以被复制；你没有说明与学校官方、书商、出版社、学生组织的排他合作，也没有说明用户转换成本。“全国大学生”这个市场越大，越容易吸引闲鱼、转转等大流量平台或学校官方直接推出同类功能。你说“第一年做到10万用户”，但即使做到，也只是“先发规模”，不构成“壁垒”。你必须回答：当资源更强的大平台或更了解本校生态的本地组织进场时，你哪一项资产能保留用户？  
- 待验证：你最容易形成的第一种防守资源是什么；形成周期多久；外部玩家复制你核心体验的成本是多少。

证据缺口：
- 用户实证：首批试点学校是哪所？种子二手书供给从哪里来？买卖双方规模如何？
- 需求证据：你访谈了多少名学生？他们现在用什么方式完成二手书交易？对现有方式的不满是什么？多少人表示愿意使用新平台并支付5%服务费？
- 竞争/迁移证据：在具体校园内，你能赢过微信群、跳蚤市场、闲鱼本地版的证据是什么？是否做过最小试点？
- 单位经济数据：客单价、订单频次、CAC、LTV、平台运营成本、5%佣金实际金额、毛利模型。
- 增长推导：第一年10万用户是通过哪些渠道、多少预算、什么转化率、多长周期获得的？“用户”指注册用户还是有效交易用户？

必须回答的问题：
① 请给出你访谈过的学生样本及关键结论：他们最近一次买/卖二手书用了什么渠道？价格多少？最不满的地方是什么？他们是否愿意为“抽5%服务费的新平台”而迁移？
② 你的5%服务费具体向谁收、在哪个环节收？请用客单价、年交易次数、获客成本和用户生命周期收入测算，说明这门生意的收入能否覆盖成本。
③ “第一年10万用户”是如何算出来的？请拆到“试点校区数 × 校区渗透率 × 注册转化率 × 获客成本”，并说明其中预期有多少用户会产生付费佣金订单。
④ 如果用户目前最大的替代方案是学校闲置群/闲鱼本地版，你能提供什么可测试的证据，证明用户会因为某个具体痛点放弃这些方案并迁移到你这里？
⑤ 你认为自己拥有哪一项资产是闲鱼、转转、学校官方或校内学生组织在3个月内无法复制的？为什么它能构成壁垒？

修改方向：
- 必须把用户定义从“全国大学生”缩小到一个能实际开展验证的校区/人群，并明确买卖双边冷启动所需的供给与需求来源。
- 必须用一手访谈、问卷或最小试点来验证“现有二手书渠道痛点足够强、用户愿意接受5%服务费并迁移”这一假设，并保留可复核记录。
- 必须建立单位经济模型，回答5%佣金实际金额是多少、向谁收、用户一年最多能产生几次付费交易、单用户收入能否覆盖获客与运营成本。
- 必须把“第一年做到10万用户”从目标口号变成渠道、预算、转化率、周期可验证的推导公式，并明确其中有多少是产生佣金收入的交易用户。
- 必须明确当前及短期可形成的防守资源；如果现在没有壁垒，则需要先承认项目存在被复制的风险，并用试点验证用户持续留在你这里的真实原因。
