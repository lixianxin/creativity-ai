## 输出

【用户洞察报告】

洞察结论：证据不足  
一句话依据：项目方仅给出“全国大学生”这一统计口径，未提供任何核心痛点、用户行为路径或需求证据，当前无法判断“用户是谁”这一基本问题。

一、用户画像清晰度  
- 项目方定义：“目标用户是全国大学生”。  
- 洞察：这不是用户画像，而是统计口径。全国大学生涵盖985、211、普通本科、专科，年级从大一新生到研三、博士，校区可能跨多城市多校区。他们在“买卖二手教材”这件事上的场景差异极大：大一新生面对的是公共课教材，高年级面对专业课书籍，研究生面对文献资料，专科生可能更多使用实训材料。不同学校、不同校区、不同专业的学生，其购书预算、闲置教材种类、校园内部交易习惯都不同。项目方现阶段的说法无法帮助识别第一批可触达的真人用户，也无法判断“哪类学校的学生最可能交易、交易什么书、在什么场景下交易”。

二、用户分层与种子用户  
- 核心用户 / 次要用户：未提供。未区分买家、卖家、买卖兼具者，也未区分活跃用书期（开学季、期末季）用户与日常长尾用户。  
- 可落地的种子用户假设：无法从材料中确定，待验证。若要落地，至少需要进一步明确类似“某城市某类本科院校的大二学生，在建有班级/宿舍群且允许线下见面的校园内，有买卖上一届专业课教材需求”这种细粒度假设。目前没有任何具体人群、场景或约束条件。

三、使用者与付费者  
- 使用者：理论上，买家使用平台查找购买，卖家使用平台上架出售。未提供更细分画像。  
- 付费者/决策者：买家付款给平台，平台抽佣后打给卖家。买家是资金的直接支出者，卖家是收入的接收者。学校、教师等第三方均未涉及。  
- 分离风险：买家、卖家均与学生重合，同一人在不同交易中可能切换角色。未发现家长/学校作为决策者的分离，但材料未提供，仍待验证。真正的风险在于：平台从买家收款后打给卖家，手续费从哪端扣除、谁承担，双方是否愿意为此切换原有交易方式，均在材料中没有任何证据。

四、核心任务与痛点（JTBD）  
- 场景与任务：材料中只描述“买卖二手教材和资料”这件事，没有描述具体场景和用户任务。用户是“在开学前快速找到指定教材”？“在期末后尽快清空旧书”？“想买到有笔记的旧教材”？“想低价买到指定版本教材？”还是“嫌电商平台发货慢/贵”？材料均未提供。  
- 痛点频率与强度：未提供，待验证。单看“二手教材”本身，用户的真实购买周期通常是一学期一次或一学期几次，发生在开学、选课、考试前。这个频率低不低、强度高不高，取决于具体痛点是否痛：如果学生只是“能买到就行”，那平台很难成为高频依赖；如果学生“必须在几天内拿到指定版本、否则影响上课”，强度可能高。但材料完全没有给出任何证据。  
- 现有不满的具体内容：未提供。项目方甚至连“现有二手书渠道有哪些问题”都没说。“买卖二手麻烦”“找不到学长学姐”“怕被骗”都只是可能痛点，不是证据。

五、用户当前行为路径  
- 用户现在如何完成该任务：未提供。这是当前最关键的缺口。学生在买二手教材时，目前真实行为是什么？是在学校二手群问？线下跳蚤市场买？直接淘宝/孔夫子/多抓鱼买新书/旧书？向学长学姐直接购买？还是在校园墙发帖？如果已有多个低成本、低摩擦的替代路径（群聊直接沟通、当面交易、无手续费），那么新平台需要给出比现有路径更强的理由，尤其是“钱先付给平台、确认收货后再打给卖家、平台抽5%服务费”这套流程比群内直接转账明显更重，用户为什么愿意选它？没有任何行为数据支撑，无法判断需求成立。

六、需求证据质量  
- 现有证据清单：  
  1. 目标用户：全国大学生——主观定义，证据等级为“主观判断”。  
  2. 核心痛点：未提供——证据等级：无。  
  3. 第一年目标10万用户——这属于目标数字，不是需求证据，证据等级：主观判断。  
- 证据局限：没有访谈、问卷、行为观察、付费预定、原型测试等任何用户证据。没有样本量，没有抽样方式，没有提问方式，唯一的口径是项目方自己设定的目标人群和目标数量，无法作为需求真实性的依据。

七、用户维度关键疑点  
- 项目方自称“目标用户是全国大学生”，但大学生内部异质大，买二手教材的使用场景、预算、交易习惯差异明显。此定义无法用于设计触达和验证需求。  
- 项目方未提供“核心痛点”，却已设定商业模式（平台代收代付、抽5%费用）。痛点未经验证直接设计收费链条，存在“解决方案先于问题”的风险。  
- 第二段描述隐含了一个假设：学生之间进行线下交易存在信任问题，所以需要平台代收货款。但材料未验证“学生之间二手书交易是否已经发生”“是否存在大量因信任而放弃交易的情况”。如果没有这个痛点，平台的核心功能就没有存在理由。  
- 平台抽5%服务费的做法将改变原有交易的成本结构。项目方未说明用户目前使用的交易路径的成本是“0元+时间成本”，还是“较低价格+沟通成本”。如果现有路径是0手续费，那么5%抽佣必须有足够突出的价值，否则买卖双方凭什么走平台？这些均无证据。

八、必须补充的用户研究（按优先级）  
① 在项目方能够触达的1-2所具体高校内，访谈30-50名真实有过“买二手教材”或“卖旧教材”经历的学生，覆盖不同专业、年级、性别，要求受访者实际展示或描述“他们在过去一次买/卖二手书的全部过程”，包括：从哪里找书、如何联系卖家、如何交易、付了多少钱、遇到什么问题、是否考虑过不用现有方式而用平台。记录行为路径，不做假设引导。  
② 观察并记录学校内3个典型渠道（如学生闲置群、校园墙、跳蚤市场）的帖子数量、响应速度、成交价格、交易是否有纠纷/骗局/跑单案例。用真实帖子和聊天记录判断“交易频次”和“信任问题”是否真实发生、发生的比例有多高。  
③ 做一个最小验证小测试：如果已有种子群（如某个学院班群），发布一个“可代管货款的二手交易规则说明”，看有多少人愿意把书挂上来卖、有多少人愿意通过平台付款购买、成交后是否愿意付5%服务费；甚至可以人工模拟托管环节，记录实际转化率。如果没有这样的群，则先从上面第①步中筛选出30位有真实卖/买需求的学生，在一周内用微信手动完成10笔真实代收代付二手书交易，测试双方的信任成本与服务费接受度。  
④ 围绕“开学前教材需求”“期末后旧书清空”两个时间节点，各观察20-30名学生的实际行为，记录他们是否主动搜索“二手教材”，交易是否被时间压力推动。这将为“痛点频率”提供参考。  
⑤ 补充访谈5-10名校方、辅导员或教务相关人员，确认是否有“教材版本统一变更”“教材发放政策”等情况。这会改变对用户任务的理解——如果教材及资料本身由学校统一采购或频繁改版，学生“自由买卖二手教材”的决策空间会大幅收缩。
