# 项目评审官案例1：二手书-十报告齐备但多负面+二清红线

- 平台：deepseek / deepseek-v4-flash
- 耗时：11.3s，tokens：2311+1331

## 输入

项目名称：校园二手书交易平台
项目描述：校园二手书交易撮合平台，目标用户全国大学生，平台代收货款后打给卖家，抽5%服务费，第一年目标10万用户。

==== 委员会各Agent报告结论摘要 ====
【用户洞察报告】结论：证据不足。“全国大学生”是统计口径非画像；痛点栏未提供；无任何访谈或行为证据；买卖双边启动问题未定义。
【市场分析报告】结论：证据不足。全国大学生非初期市场边界；TAM/SAM/SOM均无依据；SOM不得拍1%。
【竞品分析报告】结论：竞争假设存疑。闲鱼/微信群/跳蚤市场/学长赠送构成免费替代；无差异化证据；综合平台加频道成本极低。
【产品设计报告】结论：信息不足，无法可靠判断。无核心任务定义；建议先做人工MVP不开发系统；物流/社区/会员等功能明确不做。
【商业模式报告】结论：信息不足，无法可靠判断。付费方（卖家）付费价值未证明；资金虽过平台但同校面交后复购可绕开，存在去中介化断点。
【财务分析报告】结论：当前无法可靠计算。客单价/频次/CAC全缺；三情景演示下年收入量级难以覆盖团队固定成本（假设均待验证）。
【增长运营报告】结论：信息不足，无法可靠判断。核心任务未定义则激活无法定义；泛渠道全部延后。
【风险审查报告】结论：存在致命风险，待处置。致命1个：平台代收货款无支付牌照涉嫌二清；高风险6个（盗版资料、线下交易安全、学生身份核验等）。
【红队审查报告】结论：暂缓通过。致命2个：需求零证据（无任何用户访谈）；迁移与抽佣无基础（免费替代+5%抽佣方向相反）；高风险4个（画像过宽、10万用户无推导、壁垒不明等）。
【创业总指挥结论】暂缓通过；项目阶段：想法验证。

四、证据冲突与终裁
- 未发现需要终裁的冲突。
  - 各报告均不同程度给出“证据不足/存疑/致命/暂缓”的收敛结论，方向一致，不对立。
  - 财务侧重“模型难以成立/不可可靠计算”，用户洞察与红队侧重“缺乏用户证据”，两者可归入“方向已存疑且证据缺失”，不构成假冲突。

五、红线检查
- 合规致命风险：有（平台代收货款涉嫌二清）；清除条件：改由持牌机构资金托管/分账，并经风险审查官复审通过。
- 致命商业假设：有（红队：需求零证据、迁移与抽佣无基础）；是否存在真实数据推翻该等致命项：未见任何访谈、活跃或交易行为数据。
- 关键报告完整性：齐备（但关键报告结论均为负面或证据不足，完整性不改变实质判断）。
- 一票否决是否触发：是。触发项：关键红线未清除（合规二清）+ 红队致命问题未被真实数据推翻 + 风险审查结论为“待处置”。

六、证据链缺口
- 用户端：完全没有真实访谈、问卷、行为日志或试点交易数据，无法证明核心痛点存在。
- 付费方价值：未证明卖家愿意为“平台撮合”承担5%服务费，且无竞价/费率实验数据。
- 市场边界：未定义初期切入校区或学校类型，未提供对应获客路径。
- 产品核心：未定义最小可用闭环，未验证“无系统人工撮合”是否成立。
- 合规路径：未给出资金托管/二清规避方案，也未取得持牌支付或银行合作证据。

七、成熟度判断
- 综合评级：项目处于早期想法阶段，关键证据全缺，合规红线未解除，尚不具备进入路演的基础条件。
- 项目当前最硬的一块证据：竞品分析、商业模式断点与财务计算报告共同指出：免费替代和去中介化是拦路石（负面证据同向）；但没有任何可放行的正面证据。
- 项目当前最软的一块证据：用户与需求维，一份访谈或行为日志都未提供，需求假设完全悬空。

八、终审结论
暂缓，回到修改循环：退回“想法验证”环节。条件为在返回终审前，至少补充可用以验证真实需求的最小证据（访谈/人工MVP/行为日志），并清除二清红线或取得合规方案后再提交。

九、路演前必须补强 / 退回要求
- ① 先完成合规红线处置：在自有资金流方案中排除平台代收货款模式，或提供持牌机构资金托管/分账协议或替代路径，并提交风险审查官复审通过。
- ② 返回想法验证环节，补做真实用户验证：提供不少于在单一校园/社团/校内闲鱼群开展人工撮合试点或深度访谈的行为记录（对话记录、成交记录、退换货/违约等真实事件），以检验“免费替代下用户是否愿迁移并接受抽佣”的初始假定。
- ③ 在未补上以上证据前，不进入路演；商业模式与财务测算需在真实小额试点数据（定价/频次/成本）出来后再重新跑一轮商业模式、财务分析、红队审查和风险审查。
