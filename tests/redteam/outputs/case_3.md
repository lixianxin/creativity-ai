# 案例3：功能没想好-信息不足案

- 平台：deepseek / deepseek-v4-flash
- 耗时：29.7s，tokens：1634+3055

## 输入

我要做一个校园AI产品，具体功能还没想好，但我觉得市场很大。

## 红队输出

【红队审查报告】

审查结论：暂缓通过

致命问题：5个（产品未定义与信息严重不足导致五维均不可审查）
高风险问题：0个
一般问题：0个

核心漏洞：

①【用户假设｜致命】
- 攻击：你只声称“我要做一个校园AI产品”，但“校园”不是一个用户群体。大学、中学、小学、职业院校的决策链、付费能力、使用场景完全不同；即使限定在“大学生”，也分为大一到大四、不同专业、不同购买力。“用户是谁”完全缺失，等于项目没有可出发的对象。
- 待验证：最基本的问题是——首批种子用户是哪个城市、哪所学校、哪个年级、哪类角色？他们的人口规模、预算、采购流程各是什么？在你给出这些信息前，用户假设无法判断。

②【需求假设｜致命】
- 攻击：你亲口说“具体功能还没想好”，这意味着你尚未锁定任何需求；而“市场很大”是一种主观感觉，不是需求证据。你没有访谈数据、没有现有方法缺陷、没有用户愿意付费或换用新方案的证据。没有功能就不可能验证痛点是否存在、出现频率多高、现有方案有多烂。
- 待验证：需求是否真实必须用证据回答：你访谈过多少个目标用户？他们在学习和校园生活中最头疼的编号问题是什么？现在他们用什么笨办法解决？频率如何？当前方法哪一点让他们不满？

③【竞争假设｜致命】
- 攻击：在功能未定义的前提下，你无法说出任何直接竞品、间接竞品或替代方案。更关键的是：你根本没有回答“用户现在的替代方案。”哪怕同样是“校园AI产品”，通用产品例如ChatGPT、各类大模型App已经可以免费回答学习问题；校园内还有学长学姐经验、老师答疑、学校系统、微信群、纸质通知等替代信息路径。你“市场很大”的判断没有排除这些已有解决途径。
- 待验证：一个可执行的竞争分析至少要求你锁定一个明确功能方向，再列出：目标用户当前会用哪些产品/手段解决这个问题？迁移到你这里的代价和动力是什么？学校官方或巨头若入场，会怎样压制你？

④【商业假设｜致命】
- 攻击：你没有说明谁付费、收多少钱、怎么收钱，也没有固定成本、变动成本、获客成本、客户终身价值的任何假设。校园市场普遍存在“使用者不付钱、付钱者不是使用者”的问题——如果用户是学生，但他免费惯了，那付费方只能是学校或家庭，这需要额外的价值论证。没有商业模式，就不存在可审查的单位经济。
- 待验证：必须回答——你的产品是免费还是收费？如果收费，向谁收？如果不收费，获客成本和后续变现模型是什么？支撑这个模型的DAU、转化率、客单价分别是多少，依据是什么？

⑤【壁垒假设｜致命】
- 攻击：你目前只说要做“AI产品”，但“用AI”本身不是壁垒。所有AI能力、模型接口、云服务都是可采购的；校园渠道和用户数据，你没有展示任何独占资源。在功能未定、技术方案未定、数据来源未定的情况下，连“具备什么壁垒”都无法讨论，更谈不上护城河。
- 待验证：若未来真做出产品，你需要证明自己拥有以下至少一种：独特的独家数据、强网络效应、独占渠道、高转换成本、深厚算法自研能力；并获得时间来建立门槛。目前唯一能确认的是“这一切都有待验证”。

证据缺口：
- 目标用户的详细定义和首批切入点（哪个学校？哪类人？）
- 功能方向：具体解决什么任务或场景下的问题
- 需求证据：访谈人数、访谈结论、替代方案现状、痛点频率和强度
- 现有或未来潜在竞品清单，用户迁移成本
- 付费方和收入模式假设
- 成本结构、获客渠道、预期转化率与客户终身价值
- 团队可调配的资源、技术能力、校园关系、数据来源
- 任何关于“市场很大”的实际可见证据（而不是直觉）

必须回答的问题：
①你说“校园AI产品”里的“校园”，到底指谁是用户：大学生、中小学生、老师、还是学校管理部门？请给出一个具体的最初始用户群。
②你凭什么认为市场很大？你观察到了什么具体现象，还是只是泛泛而谈？
③在你“功能还没想好”的情况下，你是否已经访谈过哪怕10个校园用户？他们亲口说出来的、可用AI解决的问题是什么？
④如果这个产品现在就能上线一个简单版本，你预计谁第一个愿意用？为什么用？你计划怎么找到他？
⑤你打算如何收钱，或者说，你如何让这个产品不用补贴也能活下去？请给出最粗糙的收入来源假设。

修改方向：
- 必须先通过真实用户访谈锁定至少一个具体场景下的痛点，而不是从“市场很大”的直觉出发。
- 必须定义清“校园”中的哪一个群体、哪一个角色作为第一种子用户，并说明为什么选择他们。
- 必须在功能方向明确前推翻“没有功能也能成功”的等号，因为当前没有任何可被验证的产品形态。
- 必须验证用户当前用什么方式解决同类问题，并指出现有方案的哪个环节明显不够好。
- 必须给出一个可能的收入模型（哪怕只是假设），说明谁愿意付钱、付多少、有多少人可触达。
