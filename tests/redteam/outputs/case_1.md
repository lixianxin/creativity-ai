# 案例1：校园二手书-标准攻击案

- 平台：deepseek / deepseek-v4-flash
- 耗时：53.9s，tokens：1650+5776

## 输入

我要做一个校园二手书交易平台，目标用户是全国大学生，平台从每笔订单抽取5%服务费，我预计第一年做到10万用户。

## 红队输出

【红队审查报告】

审查结论：暂缓通过

致命问题：1个  
高风险问题：4个  
一般问题：0个  

核心漏洞：  

①【用户假设｜高】  
- 攻击：你声称“目标用户是全国大学生”。这是一个超过千万级的宽泛人群，从985到专科、从大一新生到研究生，买教材、考证书、课外书、考研资料的行为、预算和决策场景完全不同。“全国大学生”不是用户画像，只是统计口径。没有种子用户定义，就意味着无法设计获客、匹配和冷启动方案。  
- 待验证：首批种子用户具体是什么样的人？请落到具体学校类型、城市、年级、专业、交易场景；也需要验证你触达这些用户的具体渠道和数量。  

②【需求假设｜致命】  
- 攻击：你设定“要做校园二手书交易平台”，等于假设大学生需要一个新平台来解决二手书交易问题。但原文没有任何需求证据：没有访谈人数、没有问卷结果、没有对现有渠道不满的数据，也没有解释你是如何发现这个需求的。你直接跳到了商业模式和用户规模目标，但需求是否存在尚未验证。  
- 待验证：至少需要真实的需求验证数据：目标人群中现在有多少人买卖二手书、通过什么渠道、遇到什么麻烦、有多少人表示愿意用新平台。这些指标必须来自调研，不能靠常识或自我假设。  

③【竞争假设｜高】  
- 攻击：你声称用户会“通过这个平台交易”，但没有说明用户为什么不继续使用现有方案。大学生现阶段已有很多二手书处理渠道：闲鱼、转转、学校QQ/微信群、毕业季跳蚤市场、学长学姐直接卖或送。你没有任何迁移理由、差异化证据或不可替代性说明。若不解决“用户凭什么从现有地方挪到这里”，平台无法完成冷启动。  
- 待验证：目标学生当前在各替代渠道上的真实使用分布、主要不满点、迁移成本和愿意迁移的原因。  

④【商业假设｜高】  
- 攻击：你给出“平台从每笔订单抽取5%服务费”和“第一年做到10万用户”，但没有给出交易客单价、交易频次、获客成本、运营成本和支付成本。5%抽佣在低客单价、低频交易里到底能不能覆盖获客与运营是生死问题；10万用户也没有任何推导链，是什么获客渠道、什么转化率、多长周期得出这个数字？目前全部无法验证。  
- 待验证：平均客单价、年度复购次数、单笔订单毛利、CAC、LTV、支付通道费、市场费用；以及“10万用户”的具体来源拆解。  

⑤【壁垒假设｜高】  
- 攻击：全文没有提到任何壁垒。即使平台能启动，模式看起来是双边撮合：买家和卖家为什么长期留在这里？闲鱼、转转、学校官方或区域地面团队如果要复制一个类似平台，代价是什么？你没有说明形成网络效应、转换成本或独特供给的方法，因此这个项目在竞争中的自我防御能力无法判断。  
- 待验证：你计划构建的壁垒类型是什么，是数据、关系、高校独家资源、网络效应还是其他；需要多久建成；竞品复制你的成本大概是多少。  

证据缺口：  
- 真实的需求证据，而不是“我认为大学生需要”。  
- 可执行的种子用户画像和首批冷启动场景。  
- 现有替代渠道的竞争数据与用户痛点数据。  
- 客单价、订单频次、收入成本结构、获客成本等商业验证数字。  
- “10万用户”的推导过程，不是目标本身。  
- 壁垒形成路径及时间窗口。  
- 项目当前阶段、已有资源和团队能力也完全未提供，影响可执行性判断。  

必须回答的问题：  
①你如何定义第一批可以获取的用户？请具体到学校、年级、专业、书类和交易场景。  
②你调研过多少名目标大学生？其中有多少人现在买卖二手书？他们当前用什么渠道？最大的不满是什么？  
③预计单笔订单平均客单价是多少？平均每个用户每年交易几次？5%抽佣后单笔收入是多少？扣除支付通道、运营和获客成本后能剩多少？  
④如果闲鱼上线“校园二手书频道”或学校官方自己做，你靠什么让用户仍选择你？  
⑤“第一年10万用户”这个数字从什么渠道×什么转化率来？如果现在没有推导依据，你计划如何先小范围验证再放大？  

修改方向：  
- 必须把用户从“全国大学生”收窄到一个可触达、可验证的真实群体，并针对该群体的具体场景收集需求证据。  
- 必须验证“用户有需求且现有方案不够好”，而不是默认需求存在。  
- 必须通过真实客单价、频次、获客成本来验证5%抽佣模式是否成立；如果单位经济算不过账，这个模式本身需要重估。  
- 必须明确用户迁移理由和平台启动方式，否则无法进入市场。  
- 必须说明壁垒如何形成，而不是只设定用户量和抽佣目标。
