# 案例4：银发教学-付费方分离案

- 平台：deepseek / deepseek-v4-flash
- 耗时：140.9s，tokens：1656+7847

## 输入

我要做一个教老年人用智能手机的App，视频课程教他们用微信、挂号、打车，老人免费用，子女会员付费99元/年，预计第一年50万用户。

## 红队输出

【红队审查报告】

审查结论：暂缓通过

致命问题：2个
高风险问题：3个
一般问题：0个

核心漏洞：

①【用户假设｜高】
- 攻击：你声称做“教老年人用智能手机的App……老人免费用，子女会员付费99元/年”。但“老年人”这个定义过宽，年龄、城市/农村、是否已有智能手机、识字和视力情况、子女是否在身边，都会导致完全不同的使用场景和付费意愿。你没有给出首批种子用户是谁，也没有说明“免费老人用户”和“付费子女用户”的触达路径。更关键的是，使用者和付费者分离：老人用得是否开心不等于子女觉得值，付费链路没有被证明。
- 待验证：首批用户具体是哪一类老人？这类老人在哪找到？子女的付费意愿是否做过真实测试？测试结果是什么？

②【需求假设｜致命】
- 攻击：你默认老人学微信、挂号、打车，需要“视频课程”来解决。但你没有提供任何证据说明老人现在最大的障碍是“没有视频课程”。很多老人不用的原因可能是怕点错、没人陪练、手机字太小、没人帮装App、甚至根本不觉得需要学。更矛盾的是：你要让老人先学会下载、注册并打开你的App，再让他在你的App里学“怎么用其他App”。这个前置门槛没有被讨论。项目目前的“需求成立”只是一句想象。
- 待验证：你访谈/观察了多少老人和子女？老人目前遇到微信、挂号、打车不会用时，真实解决办法是什么？这些办法哪里让你判断非做这个App不可？

③【竞争假设｜高】
- 攻击：你说教微信、挂号、打车，但这些场景早有大量免费替代：子女面对面教、短视频和搜索平台上的免费教程、App自带的帮助/客服/适老模式、社区和子女单位的志愿服务等。你没有回答：用户为什么不用现有免费方案，而要再来下载一个App，并让子女付费？迁移成本包括下载、学习、注册、让老人接受一个“教学App”，这些都远高于帮你论证需求的成本。
- 待验证：目标用户在遇到“不会用”时，现在最可能找谁？他们对现有办法的不满意度有多高？什么证据说明现有办法已经不够用？

④【商业假设｜致命】
- 攻击：你说“预计第一年50万用户”，但没有说这50万是老人、子女会员还是下载量，也没给出推导链：什么渠道×多少流量×多少转化率×多少时间。99元/年的会员费，提供的是“学微信、挂号、打车”的教学内容；但学会一个具体操作通常是一次性需求。如果老人花一段时间学会常用功能，后面为什么还要续年费？你没有给出持续付费的理由。同时，免费老人用户如何转化为付费子女会员，CAC、LTV、留存、续费、视频内容制作成本和更新成本全部缺失。商业模型目前不可判断。
- 待验证：第一年50万用户的用户结构是什么？在获客成本、付费转化率、续费率、内容制作成本上，你的假设数字分别是什么？这些数字从哪里来？

⑤【壁垒假设｜高】
- 攻击：你没有提及任何壁垒。视频课程极易被复制，教学内容可被免费搬运；如果项目成立，手机厂商、微信等官方、头部App平台、电视台、公益组织都可能以“公益/适老服务”名义进入，价格可以直接免费。你的App没有网络效应，没有清晰的独家渠道，没有显著转换成本。即使需求成立，被复制的风险也极高。
- 待验证：你在未来1-2年内能形成什么别人不好复制的东西？形成这个壁垒需要多少资源和时间？

证据缺口：
- 目标老人的真实画像：年龄段、城市/农村、智能手机操作水平、子女是否在旁、文化生活背景。
- 针对“子女愿意为父母学手机付99元/年”的付费意愿数据。
- 老人现在学习智能手机使用方式的真实路径和主要障碍。
- 第一年50万用户的推导逻辑、渠道计划、成本预估。
- CAC、付费转化率、续费率、LTV、内容生产成本、团队运营成本。
- 对免费替代方案和官方公益版内容的应对方案。

必须回答的问题：
① 你如何得到“第一年50万用户”？请给出渠道、流量、转化率和时间周期的完整推导。
② 在写这个方案之前，你是否和真实的老人、子女做过需求验证？验证了具体什么问题？结论是什么？
③ 不会用智能手机的老人，如何从“不知道你的App”到“能打开你的App看视频”？这一步怎么完成？
④ 子女购买了99元/年会员，第二年续费的理由是什么？如果老人学会常用功能，会员还剩什么价值？
⑤ 如果微信官方、手机厂商或地方政府推出免费版“老年人智能手机教学”，你的差异化是什么？

修改方向：
- 必须把“老年人”收敛到尽可能具体的首批种子人群，并验证这一人群的真实使用障碍。
- 必须验证“用视频课程教老人用手机”这个产品形式是否能被老人独立使用；如果不能，需要重新考虑分发和启动路径。
- 必须证明“子女付费”不是想象，而是有真实付费心理支持的结论；付费理由需要来自目标用户，不是项目方假设。
- 必须补齐第一年50万用户的计算逻辑，以及获客成本、付费转化率、续费率等最小单位经济模型。
- 必须回答免费替代和巨头进场后，你能守住什么；如果守不住，需要重新判断项目是否能成立。
