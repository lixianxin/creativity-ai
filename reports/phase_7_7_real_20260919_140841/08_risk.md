【风险审查报告】

一、风险总览  
- 风险计数：致命 2 个 / 高 3 个 / 中 1 个 / 低 0 个  
- 总体判断：存在致命风险，待处置 —— **不解决不得进入上线、对外服务、进校试点或任何形式的公开路演**。

二、合规与法律风险  
✅ 风险点（锚定项目做法）：**系统基于大模型API直接上线对外服务，面向高校学生提供创业想法评审服务，但未说明是否完成生成式人工智能服务备案**。  
→ 等级：致命  
→ 触发条件：向不特定公众（含在校大学生）提供生成式AI内容服务（如对创业想法生成结构化评审意见、风险提示、市场分析等），且该服务具备交互性、生成性、面向公众属性。  
→ 潜在后果：违反《生成式人工智能服务管理暂行办法》关于“提供具有舆论属性或者社会动员能力的生成式人工智能服务，应当按照国家有关规定进行安全评估和备案”之义务；平台可能被责令暂停服务、下架、通报，学校采购合作亦将因合规瑕疵中止。具体备案流程与适用性待核验。  
→ 上线前必须完成的动作：**完成国家网信办生成式人工智能服务备案（含算法备案、安全评估报告、内容安全机制说明），并在产品界面显著位置标注“生成式人工智能服务标识”**。  

✅ 风险点：**机构版向高校创业学院/教务处按年采购，但未说明资金路径与合同主体——若平台以自身名义收取学校对公款项，并向学生提供服务，则构成“为学校提供教育信息化服务”，但未说明是否具备《电信业务经营许可证》（ICP证）或教育类相关资质要求**。  
→ 等级：致命  
→ 触发条件：平台作为非教育主管部门、非学校下属单位，以商业主体身份向公立高校收取年度服务费，提供覆盖教学管理场景（创业课程评审、项目遴选）的服务，且服务嵌入教学流程（如计入学分认定、院系评审依据）。  
→ 潜在后果：涉嫌无资质开展教育信息服务；若被认定为“面向中小学/高校提供学科类或教学辅助类服务”，可能触发《教育部等六部门关于规范校外线上培训的实施意见》及地方教育采购监管要求；财政资金支付需符合政府采购法，平台若无相应经营资质或未纳入地方教育信息化准入目录，合同无效、资金退回、合作终止风险极高。具体资质类型与地方准入要求待核验。  
→ 上线前必须完成的动作：**明确服务合同签约主体（须为具备合法经营资质的公司实体）、取得ICP许可证；同步启动教育信息化产品地方准入备案（如省级教育装备中心/信息中心名录申报），或提供书面说明：该服务纯属工具型AI辅助（不嵌入教学评价体系、不生成学分/成绩/官方评审结论），并由学校书面确认其使用边界**。

❌ 未发现：广告法违规（当前无广告投放）、支付业务许可（二清）问题（项目未提及平台归集/代收学生资金或押金）、双减学科类辅导红线（非学科知识传授，属创业能力评估场景）。

三、数据与隐私风险  
✅ 风险点：**学生提交“创业想法”——该内容极可能包含个人身份信息（姓名、学号、学院、联系方式隐含在上传文件/文本中）、商业秘密（产品原型、技术方案、供应链信息）、甚至地理位置（如“在XX大学周边开咖啡馆”）、消费行为偏好（目标用户画像描述）等敏感信息；但未说明数据最小必要原则执行方式、告知同意机制、存储期限与删除路径**。  
→ 等级：高  
→ 触发条件：学生在免费端口提交文本/文件，系统未在首次提交前弹出独立、清晰、分层的数据收集目的告知（区分“AI评审必需”与“运营优化可选”）、未提供单独勾选的明示同意（尤其涉及商业秘密类内容）、未说明数据是否用于模型微调、未提供一键导出与彻底删除功能。  
→ 潜在后果：违反《个人信息保护法》第十七条（告知义务）、第二十一条（委托处理需单独同意）、第四十七条（删除权）；学生主张数据泄露或滥用时，平台承担举证责任；高校采购方将因数据合规风险拒签。  
→ 上线前必须完成的动作：**上线前发布独立《AI评审服务数据处理告知书》，明确列示：①所收集字段（仅限评审必需，如创意文本、所属院校、年级——禁收身份证号/手机号/学号除非学生主动填写且标注“非必填”）；②每类数据的具体用途与法律依据；③是否用于模型训练（如是，须获单独、明示、可撤回同意）；④存储地域（境内）、期限（评审完成后30日自动匿名化，6个月后彻底删除）；⑤提供学生账户内“一键导出+永久删除”入口，并留存操作日志**。  

✅ 风险点：**机构版采购后，学校可能批量导入学生名单或评审结果数据；但未说明是否支持数据本地化部署、是否允许学校数据不出校、是否提供API对接校内统一身份认证（如CAS）**。  
→ 等级：高  
→ 触发条件：高校采购后要求数据驻留在校内服务器，或禁止学生数据出境/出域，而平台仅提供SaaS云端服务且无私有化部署选项。  
→ 潜在后果：违反《数据安全法》第三十条（重要数据处理者应开展风险评估）、《网络安全审查办法》对关键信息基础设施运营者采购活动的要求；多数985/211高校信息中心明确拒绝未经等保三级认证、无本地化能力的第三方教育SaaS接入。  
→ 上线前必须完成的动作：**提供两种合规路径之一：①完成等保三级测评并公示报告；②提供轻量级私有化部署包（支持Docker/K8s，适配主流高校云环境），并签署《数据不出域承诺函》**。  

❌ 未发现：生物识别数据收集、儿童数据（高校学生一般≥18岁，但需确认是否存在高职/预科等低龄群体；信息不足，待补充学生年龄分布说明）。

四、内容与安全风险  
✅ 风险点：**12个AI委员生成的评审意见，可能输出错误商业建议（如“建议规避专利检索”）、歧视性判断（如“下沉市场项目估值偏低”）、违法建议（如“用灰产流量起盘”）、或对少数民族/地域/性别相关创业方向做出不当归因**。  
→ 等级：高  
→ 触发条件：AI输出未经人工审核即直接呈现给学生；模型未针对创业评审场景做价值观对齐微调；缺乏输出内容安全过滤层（关键词+规则+人工复核兜底）。  
→ 潜在后果：误导学生重大决策（如放弃专利布局导致侵权）、引发舆情（如AI贬损某类群体创业能力）、触发《网络信息内容生态治理规定》第十二条（不得含有歧视、侮辱内容）；学校将因内容失当终止合作。  
→ 上线前必须完成的动作：**建立“AI输出三级过滤机制”：①前置提示词约束（强制注入“中立、合规、鼓励创新、尊重多元”指令）；②实时内容安全网关（屏蔽违法、歧视、误导性表述）；③对Top 5%高风险创业领域（如医疗健康、金融、教育培训）的评审意见强制转入人工复核池（由高校创业导师或平台持证顾问审签）**。  

✅ 风险点：**学生提交内容含违法信息（如涉军技术、传销模式、伪劣产品设计），AI委员未识别反而给出“市场潜力分析”，构成违法信息传播协助**。  
→ 等级：致命  
→ 触发条件：系统未部署违法有害信息识别模块（如涉政、涉黄、涉诈、涉密关键词库+语义模型），且无举报入口与24小时响应机制。  
→ 潜在后果：违反《网络信息内容生态治理规定》第六条（网络信息内容生产者不得制作违法信息）、第七条（平台应履行信息内容管理主体责任）；一旦被网信部门巡查发现，将按UGC平台标准追责，面临关停。  
→ 上线前必须完成的动作：**上线前集成通过国家网信办推荐目录的违法信息识别引擎（或自建经第三方检测合格的模型），部署全链路内容留痕与溯源机制；在学生提交页与结果页均设置“一键举报”按钮，承诺24小时内人工响应并反馈处置结果**。  

❌ 未发现：UGC用户发帖/评论/社交互动（本系统为单向提交-生成模式，无用户间内容交互）；线下见面履约（纯线上服务）。

五、运营与履约风险  
✅ 风险点：**依赖单一来源大模型API（如仅调用某一家厂商接口），未说明故障熔断、降级策略与备用模型切换机制**。  
→ 等级：中  
→ 触发条件：主力大模型API突发不可用（如厂商限流、区域断连、服务升级中断），导致全校学生提交后无法获取评审结果超30分钟。  
→ 潜在后果：影响教学进度（如结课答辩前集中提交）、损害学校信任、触发SLA违约（机构版合同若约定可用性≥99.9%，则需赔偿）。  
→ 上线前必须完成的动作：**实现双模型热备架构（至少接入2家合规大模型API），配置自动故障识别与秒级切换逻辑；在系统状态页实时显示服务健康度**。  

❌ 未发现：资金归集（无学生付费）、供给依赖（非人力评审，无专家资源池）、渠道单点依赖（未提仅靠老师口头推荐）。

六、伦理与社会风险  
✅ 风险点：**AI委员以“12人委员会”拟人化形式呈现评审，但未向学生清晰说明其非人类、无真实判断力、结论不具备专业背书效力，易造成“算法权威幻觉”**。  
→ 等级：高  
→ 触发条件：界面设计强化拟人感（如AI委员有头像、昵称、发言气泡），但未在每次评审结果页顶部显著标注“本结论由AI模拟生成，不构成专业投资建议或学术评价，仅供参考，请务必结合导师指导独立决策”。  
→ 潜在后果：学生过度依赖AI结论导致决策失误（如盲目修改BP放弃核心优势）；高校质疑平台误导教育主体；违反《生成式人工智能服务管理暂行办法》第四条（应采取措施防范生成虚假信息、避免误导公众）。  
→ 上线前必须完成的动作：**所有评审结果页首屏强制固定展示不可折叠提示语：“【AI模拟提示】本结论由人工智能基于通用创业知识生成，不具备法律效力、专业资质或主观判断力。请勿替代导师指导、团队讨论与市场验证。”字体加粗，背景色标黄**。  

❌ 未发现：算法歧视性训练数据（未提供训练数据构成说明，信息不足，待补充训练数据来源与去偏机制说明）；弱势群体排斥（高校学生整体数字素养较高，暂不构成系统性排斥）。

七、落地与资质风险  
✅ 风险点：**面向高校创业学院提供机构版服务，但未说明是否已取得《增值电信业务经营许可证》（ICP证）及《软件企业证书》《高新技术企业证书》等政府采购常见加分/准入资质**。  
→ 等级：高  
→ 触发条件：高校采购流程要求供应商提供ICP证（基础门槛），部分省份教育信息化采购明确要求高新技术企业资质或等保三级认证。  
→ 潜在后果：投标资格被废、无法开具合规发票、财政付款受阻。  
→ 上线前必须完成的动作：**取得ICP许可证；若计划参与政府采购，须在首单签约前完成高新技术企业认定或提供替代性合规证明（如ISO27001+等保二级以上）**。  

❌ 未发现：进校园需教育局审批（高校自主权较大，但需校内采购流程合规）；线下活动组织（无）；团队无教育行业经验（不构成落地风险，属能力短板非合规风险）。

① **完成生成式人工智能服务国家网信办备案，并在产品界面显著位置标注服务标识**（不完成不得上线对外服务）

③ **部署违法有害信息识别与处置机制，含实时过滤、举报入口、24小时响应承诺**（不完成不得开放学生提交功能）  
④ **发布符合《个人信息保护法》要求的独立数据处理告知书，落实最小必要、单独同意、删除权三项核心义务**（不完成不得收集任一学生创意文本）
