【风险审查报告】

一、风险总览  
- 风险计数：致命 2 个 / 高 3 个 / 中 1 个 / 低 0 个  
- 总体判断：存在致命风险，待处置  

二、合规与法律风险  
✅ 风险点（锚定项目做法）：**系统面向高校学生提供创业想法评审服务，基于大模型API直接上线对外服务，未说明是否完成生成式人工智能服务备案**  
→ 等级：致命  
→ 触发条件：项目已“上线对外服务”（含测试、内测、校内试用等实质对外提供AI生成内容的场景），且服务面向不特定学生用户（含未成年人可能混入），构成《生成式人工智能服务管理暂行办法》第二条定义的“向境内公众提供生成式人工智能服务”。  
→ 潜在后果：未依法履行备案义务即上线，可能被网信部门责令暂停服务、下架、通报，构成行政违法；若发生AI生成错误建议导致学生重大决策失误（如误判市场/法律风险），责任归属无备案背书将显著加剧平台法律风险。具体罚则待核验。  
→ 上线前必须完成的动作：**完成国家网信办生成式人工智能服务备案，并在产品界面显著位置公示备案编号**（备案通过前不得开放任何学生提交/评审功能）。  

✅ 风险点（锚定项目做法）：**机构版向学校采购，但未说明资金是否经平台归集、结算路径是否涉及代收代付**  
→ 等级：致命  
→ 触发条件：学校对公账户向平台公司付款 → 平台公司收款后向第三方大模型服务商（如阿里云、百度智能云）支付API调用费 → 若平台未持《支付业务许可证》或未通过持牌机构合作，构成“二清”行为（二次清算）。  
→ 潜在后果：违反《非金融机构支付服务管理办法》，涉嫌非法从事支付结算业务，面临央行处罚、账户冻结、刑事立案风险（尤其当涉及多校、多笔预付款时）。具体违法认定与罚则待核验。  
→ 上线前必须完成的动作：**明确资金路径——若平台仅作为SaaS服务方收取软件许可费，须确保学校付款为“一次性对公服务费”，不承担API调用费垫付/分账角色；若实际存在API费用代付，则必须接入持牌支付机构通道（如微信支付商户通、银联商务），并完成支付业务合作备案，禁止平台账户归集、划转学校支付款项**。  

❌ 未发现其他合规与法律风险（如广告法、反不正当竞争等，因项目无广告投放、无虚假宣传表述、无竞品贬损行为）。  

三、数据与隐私风险  
✅ 风险点（锚定项目做法）：**学生提交创业想法（含商业计划、技术方案、团队信息、联系方式等），系统必然收集学生姓名、学号、院系、手机号（注册/实名所需）、创意文本、交互日志等个人信息；但未说明是否履行最小必要原则、告知同意机制、删除权响应机制**  
→ 等级：高  
→ 触发条件：学生注册并提交想法 → 平台收集学号、手机号、创意文本等；若未在用户协议/弹窗中清晰告知收集目的、范围、存储期限、第三方共享情形（如是否向学校提供脱敏数据），且未提供便捷的账号注销与数据删除入口。  
→ 潜在后果：违反《个人信息保护法》第十三条、第十七条、第四十七条，可能引发学生投诉、监管问询、行政处罚；若发生数据泄露（如创意文本被爬取），平台无法证明已尽充分保护义务，将承担主要责任。具体罚则待核验。  
→ 上线前必须完成的动作：**上线前完成《个人信息处理规则》独立页面建设，嵌入注册流程强制阅读+主动勾选；明确标注“学号用于校验学生身份，仅留存至评审结束7日后自动删除”；提供“一键注销账号并彻底删除全部个人数据”功能（含备份数据同步清除记录）；与学校合作场景中，若需向教务处提供学生评审结果，须单独取得学生明示授权并限定数据字段（如仅提供“评审得分+改进建议”，不含原始创意文本）**。  

✅ 风险点（锚定项目做法）：**12个AI委员模拟评审，其输出内容（如“该技术存在专利侵权风险”“团队缺乏财务能力”）属于对学生的高影响力决策建议，但未说明是否建立AI输出可追溯、可复核机制**  
→ 等级：中  
→ 触发条件：AI生成评审结论 → 学生依据结论调整创业方向或放弃项目 → 若结论存在事实性错误（如误判某技术已专利化）且无法回溯提示词、模型版本、推理链，导致学生损失。  
→ 潜在后果：虽不直接违法，但构成服务可靠性缺陷，在教育场景下易引发信任危机与纠纷；若未来扩展至学分认定、竞赛推荐等强结果关联场景，风险升为高。  
→ 上线前必须完成的动作：**对每条AI评审输出，后台强制记录：调用模型名称与版本、输入提示词快照、时间戳、操作学生ID（脱敏）；前端向学生提供“查看本次评审依据说明”折叠入口（非技术细节，而是通俗解释“我们参考了哪些维度评估市场可行性”）**。  

❌ 未发现跨境数据传输风险（未提及数据出境）、生物识别信息收集（未采集人脸/声纹）等。  

四、内容与安全风险  
✅ 风险点（锚定项目做法）：**学生提交的创业想法可能包含违法不良信息（如涉政敏感类项目、涉黄赌毒技术应用、危害国家安全的AI模型训练方案），而AI委员仅做“创业评审”，未设计违法内容前置识别与拦截机制**  
→ 等级：高  
→ 触发条件：学生提交含违法关键词/意图的创业描述（如“开发翻墙工具”“设计校园贷风控模型”）→ AI委员因提示词限制未识别其违法性，反而给出“技术可行性高”等正向评审 → 内容经平台发布（即使仅限校内可见）即构成传播。  
→ 潜在后果：平台作为UGC内容提供者，未履行《网络信息内容生态治理规定》第十二条“建立健全网络信息安全管理制度”，对违法信息失管，可能被网信部门约谈、限期整改；若被用于实际违法活动，平台难辞连带责任。具体责任认定待核验。  
→ 上线前必须完成的动作：**部署双层内容安全机制：① 提交端：基于关键词库+语义模型对创业想法文本实时扫描，触发高危词（如“翻墙”“刷单”“催收”）立即阻断提交并提示“该方向不符合国家法律法规”；② 评审端：所有AI委员输出前，强制过审同一安全模型，对输出中出现的“规避监管”“灰色变现”等倾向性表述自动打标并拦截发布**。  

✅ 风险点（锚定项目做法）：**AI委员模拟真实创投委，可能生成歧视性、刻板印象类评审意见（如“女性团队在硬件领域成功率低”“文科生不适合做AI项目”）**  
→ 等级：高  
→ 触发条件：大模型训练数据隐含偏见 → 提示词未约束价值观对齐 → AI输出含性别、专业、地域等歧视性归因。  
→ 潜在后果：严重伤害学生心理与教育公平，违反《人工智能伦理规范》《新时代爱国主义教育实施纲要》关于尊重包容的要求；在高校场景下极易引发舆情与校方问责。  
→ 上线前必须完成的动作：**在全部12个AI委员的系统提示词（system prompt）中，强制嵌入价值观约束条款：“你是一名高校创新创业教育辅助AI，必须坚持客观、尊重、发展性评价原则，禁止使用任何基于性别、民族、专业、学历、地域的刻板判断；所有结论必须基于提交材料中的客观事实，不可虚构背景信息”；上线前完成至少500条歧视性话术的对抗测试，并公开测试报告摘要**。  

❌ 未发现UGC用户互动风险（本系统无学生间评论/点赞/转发功能）；未发现AI生成内容未标识风险（因评审结论明确由AI生成，属服务本质，但需在界面显著标注“本结论由AI模拟生成，仅供参考，不构成专业建议”）。  

五、运营与履约风险  
✅ 风险点（锚定项目做法）：**完全依赖大模型API提供核心服务，未说明是否有降级方案、API服务中断时的应急机制**  
→ 等级：高  
→ 触发条件：所选大模型服务商（如Qwen、GLM）出现区域性故障/调用配额耗尽/政策性接口关闭 → 学生提交后长时间无响应或返回错误 → 影响教学安排（如课程作业截止、校内路演排期）。  
→ 潜在后果：服务不可用导致学校终止采购、学生流失、品牌信誉受损；若成为教学环节刚性工具，将引发教务投诉。  
→ 上线前必须完成的动作：**制定SLA保障方案：① 至少接入2家不同厂商的大模型API（如阿里+智谱），实现自动故障切换；② 对关键评审步骤（如市场分析、风险识别）预置轻量规则引擎兜底逻辑（如关键词匹配基础建议）；③ 在系统首页公示当前服务状态（如“AI评审服务正常/降级运行”）**。  

❌ 未发现资金履约风险（此条已在“合规与法律风险”中覆盖二清问题）；未发现线下履约风险（纯线上系统）；未发现单点渠道依赖（尚未进入销售阶段，无渠道绑定）。  

六、伦理与社会风险  
✅ 风险点（锚定项目做法）：**面向高校学生（含大量18岁以下本科生），AI评审结论可能对学生创业信心、学业选择、心理状态产生强暗示影响，但未设计心理安全缓冲机制**  
→ 等级：高  
→ 触发条件：AI输出“该项目失败概率超90%”“团队能力严重不足”等绝对化否定结论 → 学生处于创业焦虑期 → 诱发自我怀疑或放弃尝试。  
→ 潜在后果：违背高校创新创业教育“重过程、轻结果”的育人导向；若批量出现负面评价，可能被校方质疑工具价值观，影响进校合作。  
→ 上线前必须完成的动作：**所有AI评审结论强制附加“成长型反馈”模块：① 禁用概率化绝对判断（删除“90%失败”表述），改为“当前材料中尚未体现XX能力，建议补充YY实践”；② 每份报告末尾固定呈现：“创业是探索过程，本次反馈聚焦材料优化，不代表对你潜力的最终判断。欢迎预约创业学院导师1对1辅导”（附校方真实预约入口）**。  

✅ 风险点（锚定项目做法）：**12个AI委员模拟“真实创投委”，但未说明是否披露其非人类属性、是否允许学生质疑AI结论、是否提供人工复核通道**  
→ 等级：中  
→ 触发条件：学生对AI结论存疑 → 无申诉路径 → 积累不满；或误以为AI委员具备真实投资决策权，产生不切实际期待。  
→ 潜在后果：教育工具公信力下降；长期可能削弱学生对真实创投逻辑的理解（混淆模拟与现实）。  
→ 上线前必须完成的动作：**在评审报告页顶部显著位置标注：“本评审由AI模拟生成，不替代真实投资决策。如对结论有疑问，可点击‘申请人工复核’，由本校创业学院导师在3个工作日内给予书面反馈”（需与合作院校签署人工复核服务备忘录）**。  

❌ 未发现算法歧视导致资源分配不公风险（本系统不涉及资源分配，仅提供反馈）；未发现弱势群体排斥风险（界面无障碍设计未提及，但属中低风险，暂标“信息不足，待补充无障碍适配方案”）。  

七、落地与资质风险  
✅ 风险点（锚定项目做法）：**面向高校提供服务，拟进入校园场景，但未说明是否具备教育行业相关资质或是否符合地方教育信息化采购要求**  
→ 等级：高  
→ 触发条件：学校以“教育信息化项目”名义采购 → 地方财政/教育局要求供应商具备《教育APP备案》《网络安全等级保护三级认证》或参与过省级教育装备目录入围。  
→ 潜在后果：无法通过学校采购流程，导致商业化受阻；若未经备案上线校内系统，可能被省级教育信息化平台下架。  
→ 上线前必须完成的动作：**启动教育部教育APP备案流程（需提供ICP备案、等保二级以上报告、隐私政策等）；同步开展等保二级测评（高校场景强烈建议升至三级）；向目标合作院校提前报备服务架构，获取《校内信息系统接入白名单》意向函**。  

❌ 未发现经营资质缺失风险（公司已有营业执照，经营范围含“人工智能应用软件开发”即可，无需特殊牌照）；团队能力未提供信息，标为“信息不足，待补充核心算法负责人教育背景与AI伦理培训记录”。  

八、红线清单（致命与高风险按优先级排序）  
① **未完成生成式人工智能服务国家网信办备案，不得开放任何学生提交与AI评审功能**（致命，法律红线）  
② **未厘清并重构资金路径，杜绝平台账户归集学校付款资金，不得启动机构版合同签署与收费**（致命，金融红线）  
③ **未部署违法内容双层拦截机制（提交端+输出端），不得允许学生提交创业想法文本**（高，内容安全底线）  
④ **未上线《个人信息处理规则》并实现“一键注销+数据彻底删除”，不得收集学生学号、手机号等身份信息**（高，隐私保护底线）  
⑤ **未完成教育APP备案及等保二级测评，不得以“校内系统”名义接入学校统一身份认证或教务平台**（高，进校准入门槛）  

九、证据缺口  
① **资金路径说明书**：需提供与学校签订的《服务合同》草案（重点看付款主体、开票科目、费用性质条款），以判定是否构成二清。  
② **AI安全机制文档**：需提供已部署的内容安全模型名称、关键词库样本、拦截策略逻辑图，验证双层拦截有效性。  
③ **教育资质进展**：需提供教育APP备案受理回执号、等保测评机构签约证明，否则无法确认高风险应对进度。  
④ **未成年人覆盖说明**：需明确说明目标高校是否招收18岁以下本科生（如少年班、英才班），以判定是否适用《未成年人保护法》第七十一条特别义务。

存在致命风险，待处置
